# 동부 시에라 + 세도나 겨울 루트 10일 (라스베가스 출발·귀환)

기존 [동부 시에라 겨울 루트 10일](./sierra-winter-route-10days.md)을 바탕으로 **후버댐을 제외하고 세도나를 추가**해 동선을 다시 짠 일정입니다.

- **시기**: 2027년 1월 중순 이전 열흘
- **항공**: 인천–라스베가스(LAS) 왕복. 귀국편은 Day 10 **저녁 출발** 필요 (세도나에서 4.5시간 운전 후 반납)
- **차량**: AWD/4WD + 체인 휴대 필수
- **거점**: 데스밸리 2박 → 비숍 3박 → 라스베가스 1박 → 세도나 3박 (총 9박)
- **동선**: 라스베가스를 축으로 서북쪽(시에라) 루프를 먼저 돌고, 돌아와서 동남쪽(세도나)으로 한 번 더 나갔다 들어오는 "8자" 동선. 시에라와 세도나가 정반대 방향이라 두 구간을 잇는 도로가 없고, 라스베가스에서 한 번 끊어 가는 것이 운전 시간이 가장 적음

**날씨**: 낮 10~15°C, 밤 영하 근처. 간혹 눈. 붉은 바위 위 눈은 오히려 사진 명소
