## 1. Chrome 설치 + 프로필 로그인

1. Safari를 열고 https://www.google.com/chrome 에서 Chrome 다운로드 → 설치
2. Chrome 실행 후 **프로필 2개**를 각각 로그인한다.
   - **회사 프로필**: 회사 구글 계정으로 로그인
   - **개인 프로필**: 개인 구글 계정으로 로그인
3. 프로필 추가 방법: Chrome 우측 상단 **프로필 아이콘 클릭 → 추가 → 로그인**
4. 로그인하면서 **동기화 켜기**를 선택하면 북마크·비밀번호·확장 프로그램이 자동으로 가져와진다.
   - 북마크가 안 보이면: `⌘ + Shift + B` 로 북마크 바 표시
   - 수동으로 가져와야 할 경우: **Chrome 메뉴 → 북마크 → 북마크 및 설정 가져오기**

> 팁: Dock에 Chrome을 고정해 두고, 회사/개인 프로필 창을 구분해서 쓰면 편하다.

## 2. OneDrive 동기화 (위치 잡기)

1. App Store 또는 https://www.microsoft.com/ko-kr/microsoft-365/onedrive/download 에서 OneDrive 설치
2. 회사(또는 개인) Microsoft 계정으로 로그인
3. 초기 설정 중 **"OneDrive 폴더 위치"** 를 물어볼 때 원하는 위치로 지정한다.
   - 기본값: `~/Library/CloudStorage/OneDrive-회사명`
   - 위치를 바꾸려면 설정 화면에서 **위치 변경** 클릭 후 원하는 폴더 선택
4. 동기화할 폴더 선택: 메뉴 막대의 OneDrive 아이콘 → **설정 → 계정 → 폴더 선택**
5. 필요하면 **파일 온디맨드**(필요할 때만 다운로드) 켜서 디스크 용량 절약
6. Finder 사이드바에 OneDrive 폴더를 드래그해서 고정해 두면 접근이 편하다.

## 3. 개인 프로그램 다운로드

순서대로 설치:

| 프로그램 | 다운로드 위치 | 비고 |
|---|---|---|
| **카카오톡** | App Store에서 "카카오톡" 검색 | 휴대폰으로 인증 로그인 |
| **Slack** | App Store 또는 https://slack.com/downloads/mac | 회사 워크스페이스 URL로 로그인 |
| **VSCode** | https://code.visualstudio.com | Settings Sync 켜서 기존 설정·확장 동기화 |
| **Claude 앱** | https://claude.ai/download | 계정 로그인 |

설치 후 공통:

- 자주 쓰는 앱은 **Dock에 고정** (앱 실행 → Dock 아이콘 우클릭 → 옵션 → Dock에 유지)
- 로그인 시 자동 실행이 필요한 앱(슬랙, 카카오톡, OneDrive)은 **시스템 설정 → 일반 → 로그인 항목**에 추가

## 4. 맥북 디스플레이·마우스 셋팅

### 4-1. 마우스 스크롤 방향 반대로

맥은 기본이 "자연스러운 스크롤"(휠 위로 올리면 화면이 아래로)이라 윈도우와 반대다. 윈도우처럼 쓰려면:

1. ** 메뉴 → 시스템 설정** 열기
2. 왼쪽에서 **마우스** 선택
3. **"자연스러운 스크롤"(Natural Scrolling)** 스위치를 **끄기(OFF)**

> 주의: 이 설정은 트랙패드와 마우스가 연동된다. 마우스만 반대로 하고 트랙패드는 그대로 두고 싶으면 무료 앱 **Scroll Reverser**(https://pilotmoon.com/scrollreverser/)를 설치해서 "마우스만 반전" 옵션을 켜면 된다.

### 4-2. 마우스 오른쪽 클릭 → 보조 메뉴

1. ** 메뉴 → 시스템 설정** 열기
2. 왼쪽에서 **마우스** 선택
3. **"보조 클릭"(Secondary Click)** 항목을 **"오른쪽 클릭"** 으로 선택

트랙패드도 같이 설정하려면:

1. **시스템 설정 → 트랙패드 → 포인트 및 클릭** 탭
2. **"보조 클릭"** 을 **"두 손가락으로 클릭 또는 탭"** 으로 선택

### 4-3. 외장 모니터 세로로 만들기 (피벗)

1. 외장 모니터를 물리적으로 90도 회전 (모니터 암/스탠드 피벗)
2. ** 메뉴 → 시스템 설정 → 디스플레이** 열기
3. 상단에서 **세로로 돌릴 외장 모니터**를 선택 (맥북 내장 화면 아님!)
4. **"회전"(Rotation)** 드롭다운에서 **90°** 또는 **270°** 선택
   - 화면이 뒤집혀 보이면 반대 각도(90° ↔ 270°)로 바꾸면 된다
5. "디스플레이 회전을 유지하겠습니까?" 확인 창에서 **확인** 클릭 (15초 안에 확인 안 하면 원래대로 돌아감)
6. 모니터 배치 정리: **디스플레이 설정 → 정렬**(Arrange)에서 모니터 아이콘을 드래그해 실제 책상 배치와 맞추기

## 추가로 해두면 좋은 것들 (선택)

- **한/영 전환 키 확인**: 시스템 설정 → 키보드 → 입력 소스 (Caps Lock으로 전환 기본)
- **Finder 설정**: Finder → 설정 → 새 Finder 윈도우에서 "홈 폴더"가 열리게 변경
- **배터리 퍼센트 표시**: 시스템 설정 → 제어 센터 → 배터리 → 백분율 보기 켜기
- **Dock 자동 숨김**: 시스템 설정 → 데스크탑 및 Dock → "Dock 자동으로 숨기기/보기"
