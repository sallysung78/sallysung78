# ⏰ 생활 리듬 기록 (기상·취침·식사)

> 매일 **기상 / 식사 / 취침 시간**만 간단히 한 줄씩. (최신 날짜가 아래로 쌓임)

| 날짜 | 기상 | 아침 | 점심 | 저녁 | 취침 | 메모 |
|------|------|------|------|------|------|------|
| _예) 08/02_ | _07:00_ | _08:00_ | _12:30_ | _18:30_ | _23:00_ | _컨디션 등_ |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

## 적는 법
- 하루에 한 줄씩 시간만 채우기 (`07:00` 형식)
- 안 먹은 끼니는 `-` 로 표시
- 메모 칸은 선택 (수면의 질, 컨디션 등)
