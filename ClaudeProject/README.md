# ClaudeProject

모바일/클로드로 작업하는 프로젝트들을 한 곳에 모아 둔 폴더입니다.

- [AI기술팁](AI기술팁/) — AI를 업무에 적용하면서 생긴 팁들 정리
- [가족법인](가족법인/) — 나중에 세금 관련을 위해 성씨네 가족법인 준비자료
- [레드햇](레드햇/) — 레드햇 제품·서비스 정보, 1:1 성과관리·업무효율화 마스터플랜
- [제주도집짓기](제주도집짓기/) — 은퇴 후 짓게 될 제주도 집 희망사항
- [집필](집필/) — 나중에 출간하고 싶은 내용들 끄적임
- [공부](공부/) — EX156(시험 정리·Lab 풀이), EX294, 레드햇 자격증 전략
- [요리](요리/) — 뵈프 부르기뇽, 사태수육·도가니탕, 소고기 부위 보관, 약고추장 등
- [냉털](냉털/) — 냉장고 털기, 남은 재료로 만든 요리
- [운동](운동/) — 그날그날 한 운동을 정리해서 누적 관리 (운동일지)
- [여행지](여행지/) — 가 보고 싶은 여행지·숙소 정보 정리
- [보험-참고자료](보험-참고자료/) — 삼성생명 가족보험 약관·특약 분석용 참고자료
- [공연업체-AgenticAI](공연업체-AgenticAI/) — 공연업체 Agentic AI 도입 플랜(개인정보 라우팅·내부 LLM·RAG)
- [disclosure-watch](disclosure-watch/) — 공시 모니터링 도구(키워드 기반 diff 리포트, Node.js)
