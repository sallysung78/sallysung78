# 마운자로 식단 가이드 (건강하게 살빼기)

> 마운자로(터제파타이드) 맞으며 다이어트. **핵심 = 단백질 지키며 정제탄수·기름·설탕 줄이기.**
> 대사증후군·지방간·공복혈당↑·근육 없음·기립성 어지럼·숨참 맞춤.

> ⚠️ **의사와 함께 관리 필수** — 특히 공복혈당·지방간·어지럼·숨참은 처방 의사에게 꼭 상의. 아래는 식단 방향 참고용.

---

## 🎯 내 조건 → 식단 방향
| 조건 | 포인트 |
|------|--------|
| 과체중·대사증후군·**공복혈당↑** | 정제탄수·설탕 확 줄이기 (흰밥·빵·면·단 음료) |
| **지방간** | 정제탄수·과당·기름진 것↓, 채소·단백질↑ |
| **근육 없음 + 마운자로** | 단백질 최우선! (약이 식욕↓ → 근손실 위험, 안 먹혀도 단백질부터) |
| **어지럼·숨참** | 수분+전해질 충분히, 무리한 저염·굶기 금지 |

## 🥗 핵심 원칙
1. **단백질 먼저** ⭐ — 매 끼 손바닥 크기 (닭가슴·생선·두부·계란·콩). 근육 지키기 = 최우선
2. **정제탄수 → 통곡물 소량** — 흰밥 대신 현미·보리 **반 공기**, 빵·면 최소화 (혈당·지방간)
3. **채소 듬뿍** — 식이섬유가 혈당·지방간·포만감 다 도움
4. **기름·튀김·설탕↓** — 굽기·삶기·찌기 (마운자로는 기름진 것 = 속 메슥)
5. **물 충분 + 전해질** — 어지럼·변비 예방 (약 부작용). 하루 1.5~2L
6. **소량씩 자주** — 식욕 줄어도 **단백질·채소 위주로** 조금씩

---

## 🍽️ 하루 식단 예시
**아침** (단백질 위주)
- 계란찜 or 두부부침 조금 + 나물 + 미역국(기름↓)
- 또는 검은콩 스프(우유 대신 두유) + 삶은 계란

**점심** (제일 든든하게)
- 닭가슴/생선 + **현미보리 반 공기** + 채소(양배추·나물)
- 또는 닭백숙(껍질·기름 제거, 찹쌀 줄이고 채소↑)

**저녁** (탄수 최소)
- 대구/황태 맑은탕 + 두부 + 나물
- 또는 두부·달걀·채소 볶음(기름 최소)

**간식** — 삶은 계란, 무가당 두유, 견과 한 줌, 오이·방울토마토

---

## ⚠️ 피할 것
- 흰밥·흰빵·면 과다, **설탕·단 음료·과일주스**, 튀김·기름진 것, 과일 과다(당)
- **굶기 금지** — 마운자로로 안 먹으면 근육 빠지고 어지럼 심해짐. 소량이라도 **단백질**은 꼭

## 💧 어지럼·숨참 특히 (중요)
- **물 자주**(1.5~2L), 국물·전해질 (나트륨 너무 안 줄이기)
- **누웠다 일어날 땐 천천히** (기립성 어지럼)
- 공복 오래 X → 소량 규칙적으로 (저혈당성 어지럼 예방)
- 가벼운 저항운동부터 — 앉았다 일어서기, 벽 팔굽혀펴기 (근육·숨참 개선)

## 🥘 요리 폴더에서 활용 (조금 변형)
- **황태국·대구 맑은탕** — 고단백 저지방, 지방간에 좋음 ⭐
- **두부 요리** — 기름 줄여 굽기(에어프라이어)
- **닭백숙/삼계탕** — 찹쌀↓, 닭+채소 위주, 껍질·기름 제거
- **미역국** — 들기름↓, 담백하게 (미역=식이섬유)
- **검은콩 스프** — 우유·감자·옥수수↓, 검은콩·양배추·당근 위주
- **양배추 메밀면** — 메밀 GI 낮음, 양↓ + 단백질(계란·닭) 추가
