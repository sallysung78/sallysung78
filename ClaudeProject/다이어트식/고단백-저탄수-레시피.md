# 고단백 저탄수 레시피 (근육 지키기)

> 마운자로 다이어트 = 단백질 최우선. 간단하고 기름 적은 한끼·반찬 모음.
> 굽기·삶기·찌기 위주, 설탕·기름 최소.

---

## 🥚 초간단 단백질 (5분)
**계란찜** — 계란 2~3개 + 물(계란의 1.5배) + 소금 조금 → 약불/전자레인지. 부드럽고 든든
**연두부 + 간장** — 연두부에 간장·참기름 조금·깨 → 조리 X, 순한 단백질
**삶은 계란 2개** — 간식·아침 대용 (근육·포만감)
**두부 스테이크** — 두부 물기 짜서 통으로 기름 조금에 노릇하게 → 간장 조금

## 🍗 닭 (기름·껍질 제거)
**닭가슴/안심 수육** — 끓는 물+대파·마늘·통후추에 삶기 → 찢어서 양념장(부추장 조금)
**닭안심 채소볶음** — 기름 최소, 닭안심 + 양배추·파프리카·양파 볶고 소금·후추
> 닭백숙(폴더)도 좋음 — 껍질 벗기고 찹쌀 줄이고 채소↑

## 🐟 생선 (저지방 고단백, 지방간 좋음)
**대구/동태 맑은탕** — 무·두부·대파 + 흰살생선, 고춧가루 없이 맑게 (or 살짝 얼큰)
**황태국** — 폴더 레시피, 들기름 줄여 담백하게
**고등어·삼치 구이** — 구워서 (기름 안 두르고 에어프라이어)

## 🥬 채소·반찬 (식이섬유)
**양배추 찜 + 쌈장 조금** — 양배추 쪄서 (포만감·저열량)
**나물류** — 시금치·콩나물 데쳐 참기름 조금·소금 (기름 적게)
**무생채·오이무침** — 아삭·저열량 (설탕 최소)
**두부 김치볶음** — 기름 줄이고 두부 넉넉히 (냉털 폴더 참고)

## 🫘 콩·통곡물 (소량)
**검은콩 스프** — 검은콩·양배추·당근 (우유 대신 두유, 감자·옥수수↓)
**현미보리밥 반 공기** — 흰밥 대신, GI 낮음 (양은 반 공기로)

---

## 🍽️ 조합 예시 (한 상)
- **닭안심 수육 + 양배추찜 + 현미보리 반공기 + 미역국**
- **대구 맑은탕 + 두부 + 나물 + 무생채**
- **계란찜 + 두부김치볶음 + 오이무침** (탄수 없이 가볍게)

## TIP
- **단백질 먼저 먹기** (혈당·포만감·근육)
- 기름은 **두르는 정도만**, 튀김 X → 굽기·삶기·에어프라이어
- 간은 **심심하게**, 설탕 대신 양파·배 등 천연 단맛
- 물 자주, 소량씩 자주 (마운자로로 식욕 줄어도 단백질은 꼭)
