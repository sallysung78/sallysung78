## 3. 성과 기술 프레임 (임팩트 서사)

### 3.1 원칙
- **액티비티는 근거(evidence)로만** 쓴다. 제목과 첫 문장에서 **"무엇을 주도했고 어떤 영향을 만들었는지"**를 직접 주장한다.
- **원격의 (외국인) 매니저가 읽어도** 평가 근거가 보이게 쓴다. 판단을 읽는 사람에게 떠넘기지 않는다.
- 가능하면 **수치**로 말한다(리드타임 단축, 후속 미팅 수, 제안 성공률, 설문 점수 등).

### 3.2 재사용 템플릿 — **STAR-I**
> 새로운 성과를 기록할 때마다 아래 5줄을 채운다. (Situation·Task→주도·Action·Result·Impact)

```
제목: [내가 주도한 것]으로 [핵심 임팩트]를 만듦  ← 한 문장으로 결론부터
상황(S): 어떤 맥락/제약이었나 (레퍼런스 부재, 규제, 높은 검증 요구 등)
주도(T/A): 내가 설계·리드한 구조/행동 (에스컬레이션, 채널 구축, 스토리라인 등)
결과(R): [수치] — 검증 통과/후속 미팅 N건/리드타임 X 단축/설문 점수 등
영향(I): 재사용 자산·확산 기반 — 이 성과가 남긴 조직적 가치
```

### 3.3 사례 1 — 우리은행 AI Agent 프로젝트

**❌ Before**
> "AI 프로젝트 초기 안정화 지원" · AI SSA와 Slack 채널 개설, PoV 채널 참여, 자료 전달
> → 무엇을 잘했는지 판단이 읽는 사람 몫. 원격 매니저가 읽으면 평가 근거 없음.

**✅ After**
> **"국내 대형은행 최초 AI Agent 프로젝트에서 글로벌–국내–고객 간 원팀 대응 체계를 리드하여 고객 신뢰 확보 및 사업 안착 견인"**
> - **상황**: 국내 은행권 첫 AI Agent 프로젝트(우리은행)로 사내 레퍼런스·경험 부재, 고객 기술검증 요구는 높은 상황.
> - **주도**: 글로벌 BU/PM–국내 팀–고객 3자 커뮤니케이션 구조를 설계하고, RHOAI 기능 갭(예: **[기능명]**)을 글로벌에 에스컬레이션하여 로드맵 회신 확보. AI SSA와 상시 협업 채널 구축으로 기술검증 리드타임 단축.
> - **결과**: **[고객 반응/검증 통과/후속 미팅 수 등 수치 기입]**. 고객 주도 후속 확산 논의로 연결.
> - **영향**: FSI AI 영역에서 재사용 가능한 대응 플레이북 확보, 타 금융 고객(**[고객명]**) 확산 기반 마련. 제안 성공률 제고에 기여.

### 3.4 사례 2 — 세미나 발표

**❌ Before**: "텔코/금융 세미나 발표 수행" — 발표했다는 팩트만 기재

**✅ After**
> **"금융 보안 패러다임 전환(Zero Trust·ZeroOps) 세션을 기획·발표하여 [N]개 고객사 후속 미팅 창출"**
> - 어떤 고민으로 구성했는지(폐쇄망 규제 대응 관점의 스토리라인), 어떤 피드백을 받았는지(참석 고객 코멘트·마케팅 설문 **[점수]**), 다음에 무엇을 개선할지 1줄씩 포함.
> - 근거 채널 다변화: 참석자 피드백 / 동석 마케팅·영업 코멘트 / 후속 요청 건수.

## 4. 우선순위 원페이저 (주간/분기)

"정신없어 보인다"는 인상은 **일이 많아서가 아니라, 우선순위 근거가 안 보여서** 생긴다. 아래 A/B/C 3분류로 항상 한 장에 정리한다.

| 구분 | 내용 | 주기 | 비고 |
|---|---|---|---|
| **A. 고객 건** | 진행 중 딜/PoC/미팅 — 건별 다음 마일스톤 1줄 | 주간 | 예: 우리은행 후속, Satellite 제안 |
| **B. 개인 목표** | RHCA(EX374 등), 승진 준비 항목, 성과 기술 업데이트 | 분기 | 기한 고정, 학습 블록 확보 |
| **C. 기타 활동** | 세미나/내부 요청/영업 지원 — 수용 여부와 근거 명시 | 주간 | 거절 시 스케줄링 근거 첨부 |

**운영**: 매주 월요일 갱신 → 화요일 1:1 공유. 신규 요청 유입 시 A/B/C에 배치하고, 조정 필요 시 **근거와 함께 제안**한다(무조건 수용 X, 무조건 거절 X — 근거 기반 협상).

```
A. 고객 건
  - [고객1] : 다음 마일스톤 = [ ] / 기한 [ ]
  - [고객2] : 다음 마일스톤 = [ ] / 기한 [ ]

B. 개인 목표 (분기 고정)
  - EX374 학습 블록: 주 [N]h / 응시일 [ ]

C. 기타 활동 (수용 여부 + 근거)
  - [요청] : 수용 / 거절 — 근거: [ ]
```

## 6. 피드백 루프 클로징 트래커
