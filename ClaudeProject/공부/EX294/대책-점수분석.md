## 3. 🚨 최우선 = 시스템관리 모듈 (15%)

35→15 급락. **본인이 hwreport(14)·cron(18)·패키지(4)를 "풀었다"고 함** → 원인은 시간이 아니라
**"풀었지만 채점 결과를 못 맞춤"**. EX294는 플레이북 작성이 아니라 **관리노드 최종 상태(end-state)** 를 채점.

### 🚨 "풀었는데 0점" 3대 원인
**A. 🔁 채점 전 재부팅에서 날아감 (제일 흔함)**
- `service` → `enabled: true` 없으면 재부팅 후 꺼짐
- `firewalld` → `permanent: true` 없으면 규칙 사라짐
- mount/swap → `state: mounted`(fstab) 아니면 사라짐

**B. 🎯 값/라벨 불일치 (했는데 채점 grep 실패)**
- hwreport(14): 라벨 `MEM` vs `MEMORY` 어긋남, `default(NONE)`(따옴표X) → **play 에러로 값 안 채워짐** (하나 틀리면 다 날아감)
- cron(18): `user: natasha` 누락 → **root crontab**에 들어가 natasha 확인 시 0점
- 패키지(4): 대상 그룹 틀림 / `"@RPM Development Tools"` 그룹명·따옴표 / 전체 업데이트 `state: latest` 누락

**C. ✅ 검증 안 해서 틀린 줄 모름**
- 만들고 실행만 하고 넘어감 → 확인명령으로 눈으로 안 보면 틀려도 모름

### 처방
- **문제마다 "채점자 관점" 확인명령**까지: `rpm -q`, `lvs`, `crontab -u natasha -l`, `cat /root/hwreport.txt`
- **재부팅 유지 3종 세트**: 서비스 `enabled:true` / 방화벽 `permanent:true` / 마운트 `state:mounted`
- hwreport는 **다운로드 후 `cat`으로 라벨 확인 → 그 라벨을 regexp에 그대로**, `default('NONE', true)` 철자 확인
- 모듈 7개(4·10·12·13·14·16·18) 반복 시 **끝에 확인명령까지** 세트로 연습

## 4. 왜 점수가 안 오를까 (핵심)

> "풀었는데 점수가 안 나온다" = **작성은 됐지만 채점 결과가 안 맞는다**. (위 3대 원인)

1. **재부팅 후 유지 안 됨** → `enabled`/`permanent`/`mounted` 빠짐
2. **값·라벨 불일치** → 정확한 문자열/그룹/사용자 확인 안 함
3. **검증 안 함** → 확인명령으로 눈으로 안 봐서 틀린 줄 모름
4. **become/권한** → 플레이 맨 위 `become: true` 또는 ansible.cfg `[privilege_escalation]` 고정

## 6. 🎭 롤이 막히는 진짜 이유 & 처방

롤은 올랐지만 아직 48%. 막히는 지점은 대부분 **"세 종류를 헷갈려서"**:

| 롤 종류 | 언제 | 핵심 | 잘 틀리는 것 |
|------|------|------|------|
| **시스템 롤** (5·6) | timesync/selinux | `vars`+`roles`, **tasks 없음** | 변수명(README 안 봄), 롤이름 접두어 |
| **갤럭시 설치** (7) | requirements | `- name/src` + **`install -r`** | collection이랑 헷갈림, roles_path |
| **커스텀 롤 생성** (8·9) | apache | `init`+tasks+template, **호출 플레이북 별도** | hosts 위치, `roles:` vs `tasks:` |

### 롤 3대 실패 원인 → 처방
1. **롤을 못 찾음** (`role not found`) → ansible.cfg `roles_path` 확인 + 설치 위치 일치 (`-p`)
2. **롤은 도는데 아무 일도 안 함** → 시스템롤 **변수명 틀림**. 반드시 **README Example 복사**해서 값만 수정
   - `less /usr/share/ansible/roles/rhel-system-roles.timesync/README.md`
3. **롤 이름/구조 혼동** → 아래 한 장 규칙

### 롤 한 장 규칙 (외우기)
```
[시스템롤]  설치: yum install rhel-system-roles
            쓰기: vars(요구값) + roles(- rhel-system-roles.xxx)   ← tasks 없음!

[갤럭시롤]  requirements.yml:  - name / src   (--- 없음)
            설치: ansible-galaxy install -r requirements.yml

[커스텀롤]  생성: ansible-galaxy init roles/apache
            내용: roles/apache/tasks/main.yml (hosts 없음!) + templates/*.j2
            호출: 별도 플레이북 → hosts + roles: (- apache)   ← tasks 아님!

[콜렉션]    ansible-galaxy collection install <파일> -p <경로>   ← install -r 아님
```
