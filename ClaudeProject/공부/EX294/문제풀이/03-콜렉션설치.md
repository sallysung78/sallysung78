# 문제 3. 콜렉션(Collection) 설치

> PPT 기출 · 주어진 URL에서 collection 파일을 받아 설치. **명령 패턴 문제**.
> 핵심: `wget` 으로 받고 → `ansible-galaxy collection install`.

---

## 1️⃣ 개념

- **Collection**: 모듈 + 롤 + 플러그인을 묶어 배포하는 단위 (FQCN: `네임스페이스.컬렉션.모듈`).
- 인터넷이 막힌 시험장에선 **`.tar.gz` 파일을 URL에서 받아 오프라인 설치**.
- 설치 위치는 `ansible.cfg` 의 `collections_path` (문제 1에서 지정한 곳).
  안 맞으면 `-p <경로>` 로 강제 지정.
- 설치 방식 2가지: **① 파일 직접** / **② requirements.yml 로 일괄**.

---

## 2️⃣ 문제 (기출 원문 요약)

> 주어진 URL에서 collection 을 설치하시오.
- URL 예: `http://ex294.redfaceh.com/materials`
- 파일: `rhel-role.tar.gz`, `community.tar.gz`, `posix.tar.gz` (3개)

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### 방법 A) 파일 직접 설치 (슬라이드 기본)
```bash
cd /home/user/ansible/____________          ← collections (cfg의 collections_path 위치)

______ http://ex294.redfaceh.com/materials/rhel-role.tar.gz    ← wget
wget http://ex294.redfaceh.com/materials/community.tar.gz
wget http://ex294.redfaceh.com/materials/posix.tar.gz

ansible-galaxy ____________ install rhel-role.tar.gz    ← collection
ansible-galaxy collection install community.tar.gz
ansible-galaxy collection install posix.tar.gz
#   위치 안 맞으면 뒤에  ____  <경로>  붙이기  ← -p
```

### 방법 B) requirements.yml 일괄 (슬라이드 08)
```yaml
# collections/requirements.yml
____________:                              ← collections   (콜렉션은 collections: 리스트)
  - name: /path/rhel-role.tar.gz
  - name: /path/community.tar.gz
  - name: /path/posix.tar.gz
```
```bash
ansible-galaxy collection install ____ requirements.yml ____ /home/user/ansible/collections
#                                  -r                    -p
```

### 🧠 외우기 포인트 (감점 함정)
- **콜렉션 = `collection install`**, 롤 = `install -r` (7번 문제와 헷갈리지 말 것!)
- requirements.yml 에서 **콜렉션은 `collections:` 리스트** (롤은 `- name/src` 리스트)
- 설치 경로 `-p` 는 **문제에 나온 경로 그대로** → ansible.cfg 의 collections_path 와 일치해야 함

---

## 4️⃣ 중요 명령어

```bash
wget <URL>/<파일>.tar.gz                                   # 파일 받기
ansible-galaxy collection install <파일>.tar.gz            # 단일 설치
ansible-galaxy collection install <파일> -p <경로>          # 경로 지정
ansible-galaxy collection install -r requirements.yml -p <경로>   # 일괄
```

---

## 5️⃣ 모듈 / 도구
- 모듈 아님 → **`ansible-galaxy` CLI** 사용 (`collection` 하위 명령).

---

## 6️⃣ 잊어버렸을 때 검색하는 법
```bash
ansible-galaxy collection install --help    # -p, -r 옵션 확인
ansible-galaxy collection list              # 설치된 콜렉션 목록 (경로별)
```

---

## 7️⃣ 테스트 후 확인 방법
```bash
ansible-galaxy collection list              # 설치된 콜렉션 나열
ls /home/user/ansible/collections/ansible_collections/   # 실제 디렉토리 확인
ansible-config dump | grep -i collections   # collections_path 확인
```

### ✅ 합격 체크리스트
- [ ] 3개 파일 모두 설치됨 (`ansible-galaxy collection list` 에 표시)
- [ ] 설치 위치가 cfg의 `collections_path` 와 일치
- [ ] `collection install` 사용 (롤용 `install -r` 아님)
