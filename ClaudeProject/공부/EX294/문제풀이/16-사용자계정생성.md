# 문제 16. 사용자 계정 생성 (user + group + Vault + password_hash)

> 🔴 취약 분야 연계 · 15번의 `locker.yml`(Vault)을 불러와 계정 생성.
> 핵심: `vars_files` + `loop` + `password_hash('sha512')` + `when` 필터. (슬라이드에서 "어려움/포기"로 표시된 난이도 高)

---

## 1️⃣ 개념

- 외부 변수 파일 2개를 `vars_files` 로 로드: **`locker.yml`**(암호, 15번) + **`user_list.yml`**(사용자 목록).
- 사용자 리스트를 `loop` 로 돌며 `user` 모듈로 생성, 보조그룹은 `group` 으로 먼저 생성.
- 암호는 **`password_hash('sha512')`** 필터로 해시.
- 사용자별 조건은 **`when: item.job == "developer"`** 로 분기.
- Vault 파일을 쓰므로 실행 시 `secret.txt`(vault 암호 파일) 필요.

---

## 2️⃣ 문제 (기출 원문 요약)

> `http://materials.classroom.com/user_list.yml` → `/home/user/ansible` 저장 후,
> `locker.yml` 을 사용해 `/home/user/ansible/users.yml` 로 계정 생성.
- **developer** 사용자: `dev`,`test` 그룹 호스트에서, 암호=`pw_developer`, 보조그룹 `devops`
- **manager** 사용자: `prod` 그룹 호스트에서, 암호=`pw_manager`, 보조그룹 `opsmgr`
- 암호는 **SHA512** 해시
- 실행 시 `secret.txt` (vault 암호 파일) 사용

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### `/home/user/ansible/users.yml`
```yaml
---
- name: create developers
  hosts: dev,test
  become: true
  ____________:                    ← vars_files
    - locker.yml
    - user_list.yml
  tasks:
    - name: devops group
      ansible.builtin.______:       ← group
        name: devops
        state: present
    - name: create dev users
      ansible.builtin.____:         ← user
        name: "{{ item.name }}"
        groups: devops
        append: true
        password: "{{ pw_developer | ____________('sha512') }}"   ← password_hash
      ______: "{{ users }}"         ← loop
      when: item.job == "____________"    ← developer

- name: create managers
  hosts: prod
  become: true
  vars_files:
    - locker.yml
    - user_list.yml
  tasks:
    - name: opsmgr group
      ansible.builtin.group:
        name: opsmgr
        state: present
    - name: create mgr users
      ansible.builtin.user:
        name: "{{ item.name }}"
        groups: opsmgr
        append: true
        password: "{{ pw_manager | password_hash('sha512') }}"
      loop: "{{ users }}"
      when: item.job == "manager"
```

### 실행 (vault 암호 파일 사용)
```bash
ansible-playbook users.yml --vault-password-file=secret.txt
#   (또는 ansible.cfg에 vault_password_file 지정 시 그냥 ansible-playbook users.yml)
```

### 🧠 외우기 포인트 (감점 함정)
- `vars_files` 로 **locker.yml + user_list.yml** 둘 다 로드
- 암호 해시: **`{{ pw_developer | password_hash('sha512') }}`**
- 보조그룹: `groups:` + **`append: true`** (기존 그룹 유지)
- 사용자 분기: `when: item.job == "developer"` / `"manager"`
- ⚠️ 외부 파일의 변수명이 `users` 인지 먼저 확인 (`cat user_list.yml`)
- 실행 시 vault 때문에 **`--vault-password-file=secret.txt`** 필요

## 5️⃣ 모듈
| 모듈 | 용도 |
|------|------|
| `ansible.builtin.group` | 보조 그룹 생성 |
| `ansible.builtin.user` | 사용자 생성 (name/groups/append/password) |
| 필터 `password_hash('sha512')` | 암호 SHA512 해시 |

## 6️⃣ 잊어버렸을 때 검색하는 법

```bash
ansible-vault view --vault-password-file=secret.txt locker.yml   # 암호 변수명 확인
```
