# 문제 14. 하드웨어 보고서 생성 (get_url + lineinfile + facts)

> 🔴 취약 분야 "Manage content" · facts 값을 파일에 치환하는 문제.
> 핵심: `get_url`로 빈 양식 다운로드 → `lineinfile`로 값 채움, 없으면 NONE.

---

## 📥 다운로드 파일(`hwreport.empty`) 실제 내용 (라벨 확인용)

```
HOST=inventoryhostname
BIOS=biosversion
MEM=memtotal
DISK_VDA_SIZE=vdasize
DISK_VDB_SIZE=vdbsize
```
> ⭐ **라벨(`HOST=`, `BIOS=`, `MEM=`, `DISK_VDA_SIZE=`, `DISK_VDB_SIZE=`)이 이미 들어있다.**
> 그래서 `touch`가 아니라 **다운로드**해야 하고, `lineinfile`의 `regexp`는 **이 라벨을 그대로** 써야 한다.
> (라벨 이름은 시험 버전마다 다를 수 있으니, 받은 뒤 `cat`으로 꼭 확인!)

---

## ⭐ 정답 (완성본 · loop 없이 5개 나열 — 실전에서 가장 안전)

```yaml
---
- name: Create Report
  hosts: all
  become: true
  tasks:
    - name: Download Empty File
      get_url:
        url: http://materials.classroom.com/hwreport.empty
        dest: /root/hwreport.txt

    - name: HOST
      lineinfile:
        path: /root/hwreport.txt
        regexp: "^HOST="
        line: "HOST={{ inventory_hostname }}"

    - name: BIOS
      lineinfile:
        path: /root/hwreport.txt
        regexp: "^BIOS="
        line: "BIOS={{ ansible_facts['bios_version'] | default('NONE', true) }}"

    - name: MEM
      lineinfile:
        path: /root/hwreport.txt
        regexp: "^MEM="
        line: "MEM={{ ansible_facts['memtotal_mb'] | default('NONE', true) }}"

    - name: VDA
      lineinfile:
        path: /root/hwreport.txt
        regexp: "^DISK_VDA_SIZE="
        line: "DISK_VDA_SIZE={{ ansible_facts['devices']['vda']['size'] | default('NONE', true) }}"

    - name: VDB
      lineinfile:
        path: /root/hwreport.txt
        regexp: "^DISK_VDB_SIZE="
        line: "DISK_VDB_SIZE={{ ansible_facts['devices']['vdb']['size'] | default('NONE', true) }}"
```

---

## 🚨 흔히 도는 답안의 오타/버그 (이거 때문에 감점!)

| 잘못 | 올바름 | 이유 |
|------|------|------|
| `regext:` | **`regexp:`** | 오타면 옵션 무시 → 줄이 교체 안 되고 끝에 추가됨 |
| `default(NONE)` | **`default('NONE', true)`** | `NONE`(따옴표X)은 미정의 변수 취급 → 에러 |
| `default(none)` | **`default('NONE', true)`** | 소문자 `none`=파이썬 None → **빈 값**으로 나옴 (문자열 "NONE" 아님) |
| `ansible_facts.ansible_bios_version` | **`ansible_facts.bios_version`** | `ansible_facts` 밑에선 `ansible_` 접두어 뺌 |

> 💡 `default('NONE', true)` 의 **`true`(두 번째 인자)** 가 중요: 값이 비었거나(false) 없을 때도 "NONE"으로 바꿔줌. `true` 없으면 빈 값은 그냥 통과됨.

---

## 1️⃣ 개념

- 빈 양식 파일을 `get_url` 로 받아 → 각 항목 값을 **facts** 로 채움.
- `lineinfile`: 파일에서 **`regexp`로 줄을 찾아** `line`으로 통째 교체. 못 찾으면 끝에 추가.
- 값이 없을 수 있으니 **`default('NONE', true)`** 로 방어.
- 파일은 `key=value` 형식, 각 줄에 단일 쌍.

---

## 2️⃣ 문제 (기출 원문 요약)

> 모든 노드에 `/root/hwreport.txt` 생성 (`/home/user/ansible/hwreport.yml`).
> 항목: 인벤토리 호스트 이름 / 총 메모리(MB) / BIOS 버전 / vda 크기 / vdb 크기
- `http://materials.classroom.com/hwreport.empty` **다운로드** → `/root/hwreport.txt`
- 올바른 값으로 수정, **없는 값은 NONE**

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### `/home/user/ansible/hwreport.yml`
```yaml
---
- name: Create Report
  hosts: ______                    ← all
  become: true
  tasks:
    - name: Download Empty File
      ____________:                ← get_url
        url: http://materials.classroom.com/hwreport.empty
        dest: /root/hwreport.txt

    - name: MEM
      ____________:                ← lineinfile
        path: /root/hwreport.txt
        ______: "^MEM="            ← regexp  (regext 아님! .empty의 라벨과 일치)
        line: "MEM={{ ansible_facts['memtotal_mb'] | ________________ }}"   ← default('NONE', true)
    # BIOS / DISK_VDA_SIZE / DISK_VDB_SIZE 도 같은 형태로 반복
```

### 🧠 외우기 포인트 (감점 함정)
- 다운로드 = **`get_url`** (url/dest), 절대 `touch` 아님 (라벨이 파일에 들어있음)
- 값 치환 = **`lineinfile`** — 철자 **`regexp`** (regext ❌)
- `regexp`는 **다운로드 파일의 실제 라벨**과 맞춤 (`^HOST=`, `^MEM=` ...)
- 없는 값 방어: **`| default('NONE', true)`** ← `true` 꼭!
- fact 표기: `ansible_facts['bios_version']`, `['memtotal_mb']`, `['devices']['vda']['size']`

### ✅ 합격 체크리스트
- [ ] `get_url` 로 hwreport.empty → /root/hwreport.txt
- [ ] `lineinfile` **regexp**(철자!)가 파일 실제 라벨과 일치
- [ ] 없는 값은 `default('NONE', true)` 로 "NONE" 문자열 출력
- [ ] `ansible_facts.bios_version` (접두어 중복 아님)
- [ ] 각 줄이 key=value 형식

## 💡 두 가지 방식 (둘 다 정답)
- **A) loop 없이 5개 나열** (위 완성본) — 라벨마다 task 하나. 헷갈릴 일 없어 **실전 추천**.
- **B) loop + 변수 리스트** — `vars`에 `hw_all`을 **직접 정의**(제공 아님!)해서 `loop: "{{ hw_all }}"`.
  코드는 짧지만 라벨/변수 실수 시 한 번에 다 틀림.
