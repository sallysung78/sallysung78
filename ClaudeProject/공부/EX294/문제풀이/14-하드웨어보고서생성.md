# 문제 14. 하드웨어 보고서 생성 (get_url + lineinfile + facts)

> 🔴 취약 분야 "Manage content" · 템플릿/facts 치환 문제.
> 핵심: 빈 파일 다운로드(get_url) → facts 값을 lineinfile로 치환, 없으면 NONE.

---

## 1️⃣ 개념

- 빈 양식 파일을 `get_url` 로 받아 → 각 항목 값을 **facts** 로 채움.
- 값이 없을 수 있으니 **`default('NONE', true)`** 필터로 방어.
- 치환은 `lineinfile`(정규식으로 줄 찾아 교체) 또는 템플릿.
- 파일은 `key=value` 형식, 각 줄에 단일 쌍.

---

## 2️⃣ 문제 (기출 원문 요약)

> 모든 노드에 `/root/hwreport.txt` 생성 (`/home/user/ansible/hwreport.yml`).
> 항목: 인벤토리 호스트 이름 / 총 메모리(MB) / BIOS 버전 / vda 크기 / vdb 크기
- `http://materials.classroom.com/hwreport.empty` 다운로드 → `/root/hwreport.txt`
- 올바른 값으로 수정, **없는 값은 NONE**

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### `/home/user/ansible/hwreport.yml`
```yaml
---
- name: hwreport
  hosts: ______                    ← all
  become: true
  vars:
    hw_all:
      - { name: "HOST",   value: "{{ inventory_hostname }}" }
      - { name: "MEMORY", value: "{{ ansible_facts['memtotal_mb'] | default('NONE', true) }}" }
      - { name: "BIOS",   value: "{{ ansible_facts['bios_version'] | default('NONE', true) }}" }
      - { name: "DISK_VDA", value: "{{ ansible_facts['devices']['vda']['size'] | default('NONE', true) }}" }
      - { name: "DISK_VDB", value: "{{ ansible_facts['devices']['vdb']['size'] | default('NONE', true) }}" }
  tasks:
    - name: download empty
      ansible.builtin.____________:  ← get_url
        url: http://materials.classroom.com/hwreport.empty
        dest: /root/hwreport.txt

    - name: fill values
      ansible.builtin.____________:  ← lineinfile
        path: /root/hwreport.txt
        regexp: "^{{ item.name }}="
        line: "{{ item.name }}={{ item.value }}"
      ______: "{{ hw_all }}"         ← loop
```

### 🧠 외우기 포인트 (감점 함정)
- 다운로드 = **`get_url`** (url/dest)
- 값 치환 = **`lineinfile`** (regexp로 줄 찾고 line으로 교체) + **`loop`**
- 없는 값 방어: **`| default('NONE', true)`** (빈 문자열도 NONE으로)
- fact 이름은 setup에서 확인: `memtotal_mb`, `bios_version`, `devices.vda.size`
- key=value 한 줄 형식 유지

---

## 4️⃣ 중요 명령어
```bash
vim /home/user/ansible/hwreport.yml
ansible-playbook hwreport.yml --syntax-check
ansible-playbook hwreport.yml
```

---

## 5️⃣ 모듈
| 모듈 | 용도 |
|------|------|
| `ansible.builtin.get_url` | 빈 양식 파일 다운로드 |
| `ansible.builtin.lineinfile` | 정규식으로 줄 찾아 값 치환 |

---

## 6️⃣ 잊어버렸을 때 검색하는 법
```bash
ansible-doc get_url        # url, dest
ansible-doc lineinfile     # path, regexp, line
# fact 이름 확인 (외우지 말고 찾기)
ansible localhost -m setup -a 'filter=ansible_memtotal_mb'
ansible localhost -m setup -a 'filter=ansible_bios_version'
ansible localhost -m setup -a 'filter=ansible_devices'
```

## 7️⃣ 테스트 후 확인 방법
```bash
ansible-playbook hwreport.yml
ansible all -m command -a "cat /root/hwreport.txt"
#   HOST=node1 / MEMORY=... / BIOS=... / DISK_VDA=... / DISK_VDB=NONE
```

- [ ] 없는 값은 `default('NONE', true)` 로 NONE 처리
- [ ] 각 줄이 key=value 형식
