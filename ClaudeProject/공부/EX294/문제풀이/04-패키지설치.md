# 문제 4. 패키지 설치

> PPT 기출 · 그룹별로 다른 패키지/그룹패키지/업데이트를 하는 **플레이북**.
> 핵심 모듈: `yum` (또는 `dnf`). 리스트 / `@그룹` / `'*'` 세 형태 구분.

---

## 1️⃣ 개념

- `yum` 모듈: 패키지 설치/삭제/업데이트.
  - **여러 패키지** → `name:` 에 **리스트**
  - **패키지 그룹** → `name: "@그룹명"`
  - **전체 업데이트** → `name: '*'` + `state: latest`
- `state`: `present`(설치) / `latest`(최신으로) / `absent`(삭제)
- 그룹마다 대상이 다르니 **task를 나눠서** `hosts` 또는 여러 play로 구성.

---

## 2️⃣ 문제 (기출 원문 요약)

> `/home/user/ansible/install-pkg.yml` 생성.
1. `dev, test, prod` 그룹 → **php, mariadb** 설치
2. `dev` 그룹 → **"RPM Development Tools"** 패키지 그룹 설치
3. `dev` 그룹 → **모든 패키지 최신 업데이트** (`state: latest`)

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### `/home/user/ansible/install-pkg.yml`
```yaml
---
- name: install php mariadb
  hosts: ______________          ← dev,test,prod   (그룹 여러 개는 콤마)
  become: true
  tasks:
    - name: install packages
      ansible.builtin.____:       ← yum
        name:
          - ______               ← php
          - ______               ← mariadb
        state: ______            ← present (또는 latest)

- name: dev group extra
  hosts: ______                  ← dev
  become: true
  tasks:
    - name: install dev tools group
      ansible.builtin.yum:
        name: "____________________"   ← @RPM Development Tools  (그룹은 @)
        state: present

    - name: update all
      ansible.builtin.yum:
        name: "______"           ← '*'   (전체)
        state: ______            ← latest
```

### 🧠 외우기 포인트 (감점 함정)
- 여러 패키지 = **리스트**, 그룹 = **`@그룹명`**, 전체 = **`'*'` + latest**
- 그룹명은 따옴표로: `"@RPM Development Tools"`
- 대상 그룹이 다르면 **play(또는 task)를 나눈다** (dev 전용 작업 분리)
- `hosts: dev,test,prod` 처럼 콤마로 여러 그룹 지정 가능

---

## 4️⃣ 중요 명령어
```bash
cd /home/user/ansible
vim install-pkg.yml
ansible-playbook install-pkg.yml --syntax-check
ansible-playbook install-pkg.yml
```

## 6️⃣ 잊어버렸을 때 검색하는 법
```bash
ansible-doc yum            # 열고 /EXAM 검색 → 리스트/그룹/전체 예제 확인
ansible-doc -s yum         # 옵션만 빠르게
```
> 💡 슬라이드 팁: `ansible-doc yum` → `/EXAM` 으로 설치 블록 긁어서 값만 수정.

---

## 7️⃣ 테스트 후 확인 방법
```bash
# 설치 확인 (해당 그룹에서)
ansible dev,test,prod -m command -a "rpm -q php mariadb"
ansible dev -m command -a "yum group list installed"
```
