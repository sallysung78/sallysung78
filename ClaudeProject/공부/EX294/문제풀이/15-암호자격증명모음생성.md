# 문제 15. 암호 자격 증명 모음 생성 (Ansible Vault)

> 🔴 **가장 취약한 분야 "Manage content(33%)"** 핵심 문제.
> Vault는 절차가 정해져 있어 **손에 익히면 확실한 득점원**. (관련: 11·14·17번)

---

## 1️⃣ 개념

- **Ansible Vault**: 암호·키 같은 민감한 변수를 **암호화**해서 파일로 저장하는 기능.
- 암호화된 파일은 그냥 열면 `$ANSIBLE_VAULT;1.1;AES256...` 로 보임(내용 안 보임).
- **vault 비밀번호**로 잠그고/푼다. 이 비밀번호를 **파일(secret.txt)** 에 저장해두면
  실행할 때 `--vault-password-file` 로 자동 입력 → 매번 타이핑 안 해도 됨.
- 이 문제는 두 단계: **(1) 변수 파일 만들기 → (2) 그 파일을 암호화**.

---

## 2️⃣ 문제 (기출 원문 요약)

> Ansible 자격 증명 모음을 생성하여 사용자 암호를 저장하시오.

- 자격 증명 모음 파일: `/home/user/ansible/locker.yml`
- 아래 **두 변수** 포함:
  - `pw_developer` = `Imadev`
  - `pw_manager` = `Imamgr`
- 암호화/해독 **비밀번호**: `thisissecert`
- 그 비밀번호는 `/home/user/ansible/secret.txt` 에 저장

---

## 3️⃣ 빈칸 (외울 것) — 손으로 채워보기 ⭐

### (1) 비밀번호 파일 `secret.txt`
```bash
echo '____________' > /home/user/ansible/secret.txt   ← thisissecert (문제의 vault 암호)
chmod ______ /home/user/ansible/secret.txt            ← 0600 (본인만 읽기)
```

### (2) 변수 파일 `locker.yml` (암호화 전, 평문으로 먼저 작성)
```yaml
____________: ______        ← pw_developer: Imadev
____________: ______        ← pw_manager: Imamgr
```
> ⚠️ key/value 파일. 플레이북 아님 → `---`·`tasks` 없이 **변수만** 적는다.

### (3) 암호화 명령 (외우기 ⭐)
```bash
ansible-vault ________ --vault-password-file=________________ /home/user/ansible/locker.yml
#             encrypt                        secret.txt(경로)
```

### 🧠 외우기 포인트 (감점 함정)
- `secret.txt` 에는 **vault 비밀번호(`thisissecert`)** 를 넣는다. (변수 아님!)
- `locker.yml` 에는 **변수 2개**(pw_developer / pw_manager)를 넣는다.
- 순서: **변수 파일 먼저 작성 → 그 다음 encrypt**. (빈 파일 암호화하고 나면 편집 번거로움)
- 명령 핵심: **`ansible-vault encrypt --vault-password-file=<파일> <대상>`**
- ⚠️ 오타 주의: 문제 원문의 비밀번호 철자를 그대로 (슬라이드는 `thisissecert` 처럼 오타 가능)

---

## 4️⃣ 중요 명령어

```bash
cd /home/user/ansible

# 비밀번호 파일
echo 'thisissecert' > secret.txt
chmod 0600 secret.txt

# 변수 파일 작성 (vim 또는 here-doc)
vim locker.yml
#   pw_developer: Imadev
#   pw_manager: Imamgr

# 암호화 (비밀번호 파일 사용 → 프롬프트 없이)
ansible-vault encrypt --vault-password-file=secret.txt locker.yml

# (대안) 비밀번호 직접 입력 방식
ansible-vault encrypt locker.yml           # → New Vault password 입력
```

---

## 5️⃣ 모듈 / 명령 도구

이 문제는 **모듈이 아니라 `ansible-vault` 명령**으로 푼다.

| 명령 | 용도 |
|------|------|
| `ansible-vault create <f>` | 새 암호화 파일을 만들며 편집 |
| `ansible-vault encrypt <f>` | **기존 평문 파일을 암호화** ← 이 문제 |
| `ansible-vault view <f>` | 복호화해서 내용 보기 |
| `ansible-vault edit <f>` | 암호화 상태로 편집 |
| `ansible-vault decrypt <f>` | 평문으로 되돌리기 |
| `ansible-vault rekey <f>` | 비밀번호 변경 (17번 문제) |

> 공통 옵션: `--vault-password-file=<파일>` 또는 `--ask-vault-pass`

---

## 6️⃣ 잊어버렸을 때 검색하는 법

```bash
ansible-vault --help                   # 하위 명령(create/encrypt/view/rekey...) 목록
ansible-vault encrypt --help           # encrypt 옵션 (--vault-password-file 확인)
```
> 💡 `ansible-vault` 는 모듈이 아니라 CLI 도구라 `ansible-doc` 이 아니라 **`--help`** 로 확인.
> 하위 명령 이름만 떠올리면(`encrypt`) `--help` 로 옵션은 바로 찾을 수 있음.

## 7️⃣ 테스트 후 확인 방법

```bash
# ① 파일이 암호화됐는지 (맨 윗줄 확인)
head -1 /home/user/ansible/locker.yml
#   → $ANSIBLE_VAULT;1.1;AES256   이면 암호화 성공

# ② 비밀번호로 내용이 제대로 풀리는지 (변수 2개 보여야 함)
ansible-vault view --vault-password-file=secret.txt /home/user/ansible/locker.yml
#   → pw_developer: Imadev
#     pw_manager: Imamgr

# ③ secret.txt 내용/권한 확인
cat /home/user/ansible/secret.txt      # thisissecert
ls -l /home/user/ansible/secret.txt    # -rw------- (0600)
```

### ✅ 합격 체크리스트
- [ ] `secret.txt` 에 vault 비밀번호(`thisissecert`) 저장, 권한 0600
- [ ] `locker.yml` 에 `pw_developer: Imadev`, `pw_manager: Imamgr` 두 변수
- [ ] `locker.yml` 첫 줄이 `$ANSIBLE_VAULT;1.1;AES256` (암호화됨)
- [ ] `ansible-vault view --vault-password-file=secret.txt locker.yml` 로 두 변수 확인됨
