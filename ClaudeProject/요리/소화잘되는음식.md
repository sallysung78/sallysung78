# 🥗 소화 잘되는 음식 (어르신·속 편한 식사)

> 기름 적게 + 푹 익혀 부드럽게 + 심심한 간 + 따뜻하게 — 이게 핵심.
> 아버님 상차림에서 "속 편한 메뉴" 고를 때 참고.

---

## 재료

### 단백질 (부드럽고 기름 적은 것)
- **흰살생선** (대구·동태·광어·조기)
- **두부·연두부**, **달걀**(반숙·찜)
- **닭가슴/안심**, 소고기는 **사태·안심** (기름 적은 부위)

### 채소 (푹 익히면 더 부드러움)
- **무·애호박·당근·시금치·양배추·감자·단호박** — 익히면 소화 쉬움
- ⚠️ 생채소·질긴 나물·고사리·버섯 껍질은 부담 → 푹 익혀서

### 탄수화물
- **흰죽·진밥·미음**, **감자·고구마·단호박**, 부드러운 **국수·수제비**

### 과일
- **바나나·잘 익은 배·사과**(익히거나 갈아서) — 위에 순함

---

## 조리법
| 좋은 방법 ✅ | 피할 것 ❌ |
|------|------|
| **찌기·삶기·끓이기** (기름 적음) | 튀김·부침 (기름 많음) |
| **푹 익혀 부드럽게** | 센불 볶음·구이 겉바속촉 |
| **잘게·으깨서** | 질긴 덩어리 통째 |
| **따뜻하게** | 너무 차갑거나 뜨겁게 |
| 간 **심심하게** | 맵고 짜고 자극적 |

---

## 대표 소화식
1. **호박죽 / 흰죽 / 전복죽** — 위에 가장 순함 (아플 때·아침)
2. **달걀찜** — 부드럽고 단백질, 어르신·아이 다 좋아함
3. **두부·애호박 된장국** (심심하게) — 자극 적고 구수함
4. **대구/동태 맑은 탕(지리)** — 흰살생선, 고춧가루 없이 맑게
5. **닭안심 야채죽 / 삼계죽** — 기력 보충 + 소화 부담 적음
6. **감자·단호박 찜/스프** — 부드럽고 든든
7. **무·소고기 뭇국** (맑게) — 무가 소화 도와줌
8. **연두부 + 양념간장** — 조리 없이 간단한 순한 단백질

---

## 소화 돕는 팁
- **무·양배추**는 소화효소가 있어 도움 (익힌 무 추천)
- 식후 **따뜻한 물·생강차·매실차** 한 잔
- **소량씩 자주**, 천천히 꼭꼭
- 기름진 것·과식·늦은 식사 피하기
