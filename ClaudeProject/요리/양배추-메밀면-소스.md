# 양배추 메밀면 (비빔 소스)

> 삶은 메밀면 + 양배추채에 쓱쓱 비벼 먹는 간장 들기름 소스.
> 고소하고 새콤달콤, 담백해서 다이어트·한 끼로 딱.
> **메밀면 80g 기준.** (출처: 인스타 하람키친)

---

## 🥢 소스 (메밀면 80g 기준)
| 재료 | 분량 |
|------|------|
| 양조간장 | 1.5큰술 |
| 식초 | 0.5큰술 |
| 들기름 | 1.5큰술 |
| 알룰로스 | 1.5큰술 |
| 간 깨(깨소금) | 1큰술 |

> 다 섞으면 끝. 고소한 들기름 + 새콤달콤 간장베이스.

---

## 만드는 법
1. **소스** 재료 다 섞어두기 (양조간장 1.5 · 식초 0.5 · 들기름 1.5 · 알룰로스 1.5 · 간깨 1)
2. **양배추 채썰기** — 얇게. (씻어서 물기 빼기)
3. **메밀면 삶기** — 끓는 물에 80g, 포장 시간대로(보통 3~5분) → **찬물에 빡빡 헹궈** 전분 제거 → 물기 빼기
4. 그릇에 **메밀면 + 양배추채 + 소스** 넣고 쓱쓱 비비기
5. (선택) 깨·김가루·계란지단·오이채 올리기

---

## TIP
- **양배추는 채 썰어 찬물에 담갔다 빼면** 아삭함↑ (물기는 꼭 제거 — 소스 묽어짐 방지)
- 메밀면은 **찬물에 헹궈 차갑게** 해야 쫄깃하고 시원함 (여름 별미)
- 매콤하게: **청양고추·고춧가루** 조금 추가
- 단백질 보강: 삶은 계란·닭가슴살·두부 곁들임
- 알룰로스 없으면 → 올리고당/꿀/설탕으로 대체 (단맛 조절)
- 들기름 대신 참기름도 OK (향 차이)
