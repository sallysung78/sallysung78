# 매운 쪽갈비찜 (돼지 등갈비/쪽갈비)

> 매콤달콤 양념에 푹 조린 쪽갈비. 밥도둑!
> **아이도 먹게 맵기 조절** 버전 포함. 전기압력밥솥 활용. 3~4인분.

---

## 재료 (3~4인분)
### 메인
| 재료 | 분량 |
|------|------|
| 돼지 쪽갈비(등갈비) | 1kg |
| 감자 | 2개 |
| 당근 | 1개 |
| 양파 | 1개 |
| 대파 | 1대 |
| 떡국떡·가래떡 (선택) | 한 줌 |

### 양념장
| 재료 | 분량 |
|------|------|
| 고추장 | 2큰술 |
| 고춧가루 | 2~3큰술 (맵기 조절) |
| 간장 | 4큰술 |
| 설탕 | 2큰술 (+ 물엿 1큰술) |
| 다진 마늘 | 1.5큰술 |
| 다진 생강 | 0.5큰술 |
| 청주(맛술) | 2큰술 |
| 참기름 | 1큰술 |
| 후추 | 약간 |
| 물 또는 육수 | 1.5~2컵 |

---

## 만드는 법
1. **핏물 빼기** — 쪽갈비 찬물에 30분~1시간 (누린내 핵심). 중간에 물 갈기.
2. **데치기** — 끓는 물에 대파·통후추 넣고 **5~7분 데쳐** → 버리고 헹구기 (기름·잡내 제거).
3. **채소 손질** — 감자·당근 큼직하게 모서리 다듬기, 양파 큼직하게.
4. **양념장** 섞기.
5. **압력밥솥에** — 쪽갈비 + 양념장 + 감자·당근 + 물/육수 (자작, **최대선 아래**).
6. **찜/갈비찜 모드 25~30분.**
7. ⭐ **자동 감압 전 취소 → 자연감압 10~15분** (분출 방지). 핀 내려가면 뚜껑.
8. 뚜껑 열고 **양파·대파·(떡)** 넣고, 뚜껑 연 채 **중불로 5~10분 졸여** 윤기.
9. 간 보고 → 매콤함↑ 고춧가루, 단맛↑ 물엿, 감칠맛↑ 간장.

---

## 👶 아이도 먹게 (맵기 조절)
- **제일 쉬운 법 — 순한 베이스 + 어른만 매운맛 추가:**
  1. 양념에서 **고추장·고춧가루 확 줄이고**(고추장 1, 고춧가루 0.5) 간장·설탕 베이스로 만들기 → 아이용 간장 쪽갈비
  2. 다 조린 뒤 → **아이 몫 먼저 덜어내고** → 남은 것에 **고춧가루·고추장·청양고추** 더 넣고 조려 어른용 매콤하게
- **덜 맵게 하는 재료:** 설탕·물엿·**배즙**·양파 늘리기 (단맛이 매운맛 눌러줌), 우유 조금
- 아이가 조금 매운 거 OK면 → 고춧가루만 1큰술로 줄이고 설탕 넉넉히

---

## TIP
- 더 부드럽게: 압력 시간 5분 더 (뼈에서 살 발라질 정도)
- **하루 전 만들어 식히면** 기름 굳어 걷기 쉽고 + 맛 배임
- 감자·당근은 오래 익혀야 하니 처음부터, **떡·양파·대파는 마지막에**(양파 뭉개짐·떡 불음 방지)
- 국물 자작하게 남겨 밥 비벼 먹으면 별미
- 데치기 + 생강·청주 = 돼지 누린내 확실히 제거
