# 두부 동그랑땡

> 고기 없이 두부로만 만드는 동그랑땡. 부드럽고 담백, 아이·어르신 좋음.
> (출처: 인스타 레시피)

---

## 재료
| 재료 | 분량 |
|------|------|
| 두부 | 1모 |
| 양파 | 1/2개 |
| 당근 | 1/3개 |
| 부추 | 약간 |
| 전분가루 | 1T |
| 계란 | 3알 |
| 야채가루 | 1포 |
| 소금 | 1t (작은술) |

---

## 만드는 법
1. **두부 물기 꼭 짜서** 준비, 양파·당근·부추 모두 다지기
2. **두부 + 야채 + 전분가루 + 계란 + 야채가루 + 소금** 모두 섞어 반죽
3. **달군 기름에 앞뒤 노릇하게 구우면** 완성

---

## TIP
- **두부 물기 꼭 짜기** (안 그러면 질어져 안 뭉침) — 면포에 짜면 확실
- 반죽 질면 → 전분 조금 더
- 중불로 노릇하게 (센불이면 겉만 타고 속 안 익음)
- 초간장(간장+식초) 찍어 먹기
- 야채가루 없으면 → 소금·후추로 간 조절
