# 약고추장 비빔밥

> 이미 만들어둔 [약고추장](약고추장.md)으로 뚝딱. 나물·계란 올려 비비면 끝.
> 남은 나물·냉장고 야채 활용 좋음. 여름 입맛 살리기 딱. 2~3인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 따뜻한 밥 | 2~3공기 |
| 약고추장 | 밥마다 1~2큰술 |
| 계란 (프라이/반숙) | 인원수대로 |
| 나물류 | 있는 대로 |
| 참기름·깨 | 약간 |

### 올리면 좋은 것
- **나물:** 시금치, 콩나물, 애호박볶음, 고사리, 무생채
- **생채소:** 상추·깻잎 채, 오이채, 당근채
- **기타:** 김가루, 볶은 김치, 계란지단

---

## 만드는 법
1. 밥 위에 **나물·채소 색 맞춰** 돌려 담기.
2. 가운데 **약고추장 1~2큰술** + 계란 프라이.
3. 참기름·깨 뿌려 내기 → 먹기 직전 쓱쓱 비비기.

---

## TIP
- 약고추장이 이미 간이 세니 **조금씩 넣어 간 조절** (짜지 않게).
- 어르신용은 나물 부드럽게, 밥 질지 않게.
- **돌솥/뚝배기**에 참기름 두르고 밥 눌리면 누룽지 비빔밥 → 별미.
- 여름엔 **열무·얼갈이 겉절이** 곁들이면 최고.
