# 된장찌개 + 우렁 쌈밥 (여름 제철상)

> 우렁이 6~8월 제철! 쌈 채소에 밥 + 우렁 강된장 얹어 싸 먹는 여름 보양·입맛상.
> 어르신상으로 딱. 4인분.

---

## 🌞 여름에 적당한가? → ✅ 매우 적당
- **우렁 제철(6~8월)**, 쌈 채소도 여름이 풍성.
- 뜨거운 국물이지만 **쌈 + 생채소**라 개운하고, 입맛 없을 때 밥 잘 넘어감.

---

## A. 우렁 강된장 (쌈장 겸)
### 재료
| 재료 | 분량 |
|------|------|
| 우렁살 (데친 것) | 200g |
| 된장 | 3큰술 |
| 고추장 | 1큰술 |
| 다진 마늘 | 1큰술 |
| 양파·애호박·표고 다진 것 | 1컵 |
| 청양고추 | 1~2개 |
| 멸치육수 또는 쌀뜨물 | 1.5컵 |
| 들기름 | 1큰술 |

### 만드는 법
1. 들기름에 다진 채소 볶기 → 된장·고추장·마늘 넣고 더 볶기.
2. 육수 붓고 끓이다 **우렁살** 넣고 자작하게 **10~15분 되직하게** 졸이기 (쌈장처럼 걸쭉하게).
3. 청양고추 넣어 마무리.

---

## B. 된장찌개 (국물용, 원하면)
호박·두부·양파·버섯·청양고추 + 된장 풀어 멸치육수에 끓이기.
> 강된장으로 대체 가능 — **둘 중 하나만 해도** 충분. 상 간소화하려면 강된장 하나로 쌈장+국 겸용.

---

## C. 쌈 세팅
- **쌈 채소:** 상추·깻잎·양배추 찐 것·호박잎 찐 것·양파
- 따뜻한 밥, 우렁 강된장, (선택) 제육이나 수육 곁들임

## 먹는 법
쌈 채소에 **밥 + 우렁 강된장** 얹어 싸 먹기. 호박잎쌈은 살짝 쪄서 내면 어르신들이 특히 좋아하심.

---

## TIP
- 우렁은 **너무 오래 끓이면 질겨짐** → 마지막에 넣기.
- **호박잎·양배추 쪄서** 내면 부드러워 어르신 쌈으로 좋음.
- 강된장 하나로 쌈장 + 찌개 겸하면 준비 간단.
