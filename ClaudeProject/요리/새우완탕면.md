# 새우완탕면 (새우만두 + 소면)

> 새우만두를 완탕처럼, 소면을 면으로 → 완탕면 스타일. 간단하고 든든.
> **닭+양지 육수** 있으면 국물 진하게! 2인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 소면 | 2인분 |
| 새우만두 | 6~8개 |
| 부추 | 한 줌 (송송) |
| 대파 | 1대 |
| 다진 마늘 | 0.5큰술 |
| 계란 (선택) | 1개 (지단) |

### 육수
- **닭+양지 육수 : 물 = 반반** ⭐ (진한 육수라 희석)
- 국간장·소금·후추로 간, (참기름 몇 방울)
- ※ 육수 없으면 멸치육수나 물+치킨스톡

---

## 만드는 법
1. **육수 끓이기** — 닭+양지육수 반 + 물 반 + 다진 마늘 → 끓으면 **국간장·소금으로 간** (완탕면은 슴슴~적당하게). 후추·참기름 살짝.
2. **새우만두는 육수에 넣어 익히기** (냉동 5~7분, 떠오르면 익음) → 건져두기
   - 육수에 삶으면 **만두맛이 국물에 배어** 더 좋음. 약중불로(팔팔하면 터짐)
3. **소면은 따로 삶기** ⭐ — 끓는 물에 3~4분(끓어오르면 찬물 반 컵씩 2~3번) → **찬물에 헹궈** 전분 빼고 사려두기
   - ⚠️ 소면을 육수에 삶으면 **국물 탁하고 짜짐** → 꼭 따로!
4. **합치기** — 그릇에 소면 담고 → 만두 얹고 → **뜨거운 육수 붓기**
5. **부추·대파 송송**, (계란지단·김) 고명

---

## 🥢 만두 찍먹 간장소스
**기본:** 간장 1 + 식초 1 + 물 0.5(or 육수) + (고춧가루 조금·다진 마늘·청양고추·참기름·깨)
**참소스 활용:** 참소스 그대로 or **참소스 + 간장 조금 + 식초 살짝**(고소+짭짤, 느끼함 잡힘)

---

## TIP
- **소면 따로 삶기 = 필수** (국물 맑게). 만두는 육수에 삶아 맛 배게.
- 육수 진하면 물로 희석 + **간 보며** 조절 (간 된 육수는 특히)
- 부추는 마지막에 (향 살림). 만두는 약중불로(안 터지게).
- 중화풍 원하면 → **굴소스 1작은술 + 후추 + 참기름**
- 얼큰하게 → 고춧가루·청양고추
- 새우 껍질 있으면 볶아 육수 내면 새우향↑
