# 갈비탕 + 잡채 (강강술래 스타일)

> 갈비탕은 맑게 끓이고, 잡채는 강강술래처럼 달큰·짭조름·윤기 도는 스타일로.
> 잔칫상·어르신상 단골 조합. 각 4인분.

---

## A. 갈비탕
### 재료
| 재료 | 분량 |
|------|------|
| 소갈비 (탕용) | 1kg |
| 무 | 1/4개 |
| 대파 | 2대 |
| 마늘 | 5쪽 |
| 통후추 | 약간 |
| 소면 또는 당면 (선택) | 적당량 |
| 소금·후추 | 간용 |

### 만드는 법
1. 갈비 **찬물에 2시간 핏물 빼기** (중간 물 갈기).
2. 끓는 물에 **5분 데쳐** 버리고 헹구기 (국물 맑아짐).
3. 새 물에 갈비 + 무 + 대파뿌리 + 마늘 + 통후추 넣고 **1시간 30분~2시간** 푹.
   - 압력솥이면 30~40분 + **자연감압**.
4. 무는 중간에 건져 나박 썰기. 국물 **기름 걷기**.
5. 그릇에 갈비·무·송송 대파 담고 뜨거운 국물 부어 소금·후추 간. (밥 말거나 소면 곁들임)

> TIP: 맑게 하려면 데치기 필수. 기름은 식혀서 걷으면 깔끔. 전날 끓여두면 편하고 맛 깊어짐.

---

## B. 잡채 (강강술래 스타일)
### 재료
| 재료 | 분량 |
|------|------|
| 당면 | 200g |
| 소고기 (불고기감) | 150g |
| 시금치 | 1줌 |
| 당근 | 1/2개 |
| 양파 | 1/2개 |
| 표고버섯 | 3개 |
| 목이버섯 (선택) | 약간 |
| 파프리카 (선택) | 1/2개 |

### 양념 (당면 밑간)
| 재료 | 분량 |
|------|------|
| 간장 | 4큰술 |
| 설탕 | 2큰술 |
| 참기름 | 2큰술 |
| 굴소스 (선택) | 1작은술 |
| 다진 마늘 | 1작은술 |
| 깨·후추 | 약간 |

### 만드는 법
1. 당면 **찬물에 30분 불리기**.
2. 채소·고기 **각각 따로 볶기** (색 선명하고 물 안 생김). 시금치는 데쳐 참기름·소금 무침.
3. 당면 삶아(6~7분) 건져 **팬에서 간장·설탕 양념과 함께 볶아** 밑간 배게 하기.
4. 볶은 재료 다 넣고 참기름·깨 넣어 버무리기.

> **강강술래 스타일 포인트:** 간장·설탕 넉넉히 + 참기름 넉넉히 → 달큰·짭짤·윤기. 굴소스 살짝이 감칠맛 비결.

---

## 미리 하기
- **갈비탕:** 전날 끓여 기름 걷고 당일 데우기.
- **잡채:** 몇 시간 전 무쳐두면 간 배어 더 맛남 (너무 오래 두면 당면 붇음 → 참기름 더 둘러 살리기).
