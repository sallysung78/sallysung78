# 사태 장조림 (삶은 사태 활용)

> 삶은 사태로 뚝딱 만드는 짭짤 밑반찬. 이미 익어서 간단!
> 결대로 찢으면 밥반찬 딱, 냉장 1주일. (사태=고단백 저지방)

---

## 재료
| 재료 | 분량 |
|------|------|
| 삶은 사태 | 400~500g (결대로 찢거나 큼직 썰기) |
| 간장 | 1/2컵 (100ml) |
| 물 또는 삶은 육수 | 1.5컵 |
| 설탕 | 2~3큰술 (다이어트면 1큰술) |
| 마늘 | 8~10쪽 |
| 청양고추·꽈리고추 | 적당량 |
| 통후추 | 약간 |
| (선택) 삶은 계란·메추리알 | 적당량 |

---

## 만드는 법
1. 삶은 사태 **결대로 찢기** (or 큼직 썰기) — 이미 익었으니 손질만
2. 냄비에 **간장 + 물(육수) + 설탕 + 마늘 + 통후추** 끓이기
3. 끓으면 **사태 넣고 중약불 15~20분** 조리기 (이미 익었으니 오래 X, 간 배고 국물 졸면 됨)
4. **청양·꽈리고추, (삶은 계란)** 넣고 5~10분 더
5. **국물 자작해지면** 완성

---

## 🔑 포인트
- **삶은 사태라 조리 짧음** (생고기는 삶아야 하는데 생략)
- 사태는 **결이 있어 찢으면** 장조림에 딱 (결결이 간 배임)
- **삶은 육수 있으면 물 대신** → 감칠맛↑

## ⚠️ 팁
- **간장 : 물 = 1 : 1.5~2** (짜지 않게, 조리면 농축됨)
- **국물 너무 졸이지 말기** — 식으면 더 짜짐 (자작하게 마무리)
- 매운 거 → 청양고추 / 순하게 → 꽈리고추만
- 결대로 찢으면 밥반찬, 큼직 썰면 씹는 맛

## 🍽️ 보관·활용
- **냉장 1주일** (짭짤해 오래감)
- 밥도둑 / 김밥·주먹밥·비빔밥 재료

## 🥗 다이어트(마운자로) 버전
- **설탕 1큰술로 줄이기** (저당)
- 사태 = **고단백 저지방** → 근육 지키기 좋음 ⭐
- 국물 짜니 조금씩, 채소랑 같이
