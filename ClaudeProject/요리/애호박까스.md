# 애호박까스

> 애호박을 튀김옷 입혀 노릇하게 튀긴 채소 까스. 담백하고 아이도 좋아함.
> (출처: 인스타 레시피 / 계량스푼 1T=15ml, 1t=5ml)

---

## 재료
| 재료 | 분량 |
|------|------|
| 애호박 | 1개 |
| 소금 | 약간 (절임용) |
| 전분가루 | 반 컵 |
| 계란 | 2개 |
| 빵가루 | 2컵 |

---

## 만드는 법
1. **애호박** 길게 잘라 **6등분** → **소금에 10분 절이기**
   - 💡 껍질쪽엔 전분이 잘 안 묻으니 **감자칼로 껍질 얇게 벗기면** 좋아요
2. 절인 애호박 **물기 닦고** → **전분가루 → 계란물 → 빵가루** 순으로 입히기
3. **달군 기름에 앞뒤 노릇하게 튀기면** 완성

---

## TIP
- 물기 잘 닦아야 튀김옷이 잘 붙고 바삭
- 튀김기름 넉넉히 + 중불~중강불 (겉바속촉)
- 케첩·머스터드·돈까스소스 찍어 먹기
- 살짝 절이면 간 배고 물기 빠져 눅눅함↓
