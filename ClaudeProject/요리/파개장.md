# 파개장 (대파 육개장)

> 고기 대신 대파·버섯으로 얼큰하게 끓인 육개장 스타일. 간편하고 시원·칼칼.
> 아이용은 고춧가루 전에 덜어내면 순하게. (출처: 인스타 레시피)

---

## 재료
| 재료 | 분량 |
|------|------|
| 대파 | 3대 |
| 다진 마늘 | 1T |
| 느타리버섯 | 한 줌 |
| 고춧가루 | 2T |
| 계란 | 2알 |
| 한우가루(소고기 다시가루) | 2포 |
| 액젓 | 1T |
| 후추 | 약간 |
| 물 | 800ml |

---

## 만드는 법
1. **대파** 반 갈라 길쭉하게 썰고, **느타리** 결대로 찢기
2. 기름 두른 냄비에 **대파·마늘 달달 볶다가** → (아이들 것 덜어내고) **고춧가루 넣어 고추기름 나오게** 볶기
   - 물 800ml 넣고 → **버섯·한우가루·액젓으로 간** → **10분 끓이기**
3. 마지막에 **계란물 풀어** 넣고 1분 뒤 국자로 살살 풀어주기 → 계란 다 익으면 완성 (+후추 마무리)

---

## TIP
- 대파를 **푹 볶아야** 단맛·감칠맛 나옴 (파개장 맛의 핵심)
- 아이용은 **고춧가루 넣기 전에 덜어서** 순하게 (맑은 파국)
- 한우가루 없으면 → 소고기 다시다·비프스톡으로 대체
- 계란은 넣고 **바로 젓지 말고** 1분 뒀다 살살 (몽글하게)
- 밥 말아 먹으면 든든
