# 소갈비찜 (아버님 상차림용)

> 비프 부르기뇽 대신 한식 메인으로. 부드럽고 달큰해서 어르신 입맛에 딱.
> 전기압력밥솥 활용 (감압 주의 — 아래 참고). 4인분.

---

## 재료 (4인분)
### 메인
| 재료 | 분량 |
|------|------|
| 소갈비 (찜갈비) | 1kg |
| 무 | 1/3개 |
| 당근 | 1개 |
| 양파 | 1개 |
| 대파 | 1대 |
| 표고버섯 | 3~4개 |
| 밤·대추 (선택) | 적당량 |

### 양념장
| 재료 | 분량 |
|------|------|
| 간장 | 6큰술 |
| 설탕 | 2큰술 (+ 물엿 1큰술) |
| 배 간 것 또는 배즙 | 1/4개 |
| 다진 마늘 | 1큰술 |
| 다진 생강 | 1작은술 |
| 청주(맛술) | 2큰술 |
| 참기름 | 1큰술 |
| 후추 | 약간 |
| 물 또는 육수 | 1.5~2컵 |

---

## 만드는 법
1. **핏물 빼기:** 갈비를 찬물에 1~2시간 담가 핏물 빼기 (중간에 물 갈기). 어르신용은 이 단계가 누린내 잡는 핵심.
2. **데치기:** 끓는 물에 5~7분 데쳐 기름·불순물 버리고 헹구기.
3. **채소 손질:** 무·당근 큼직하게 썰어 **모서리 다듬기**(각지면 부서짐). 양파·표고 큼직하게.
4. **양념장** 섞어두기.
5. **압력밥솥에:** 갈비 + 양념장 + 무·당근 + 물/육수. (양파·표고·대파는 나중에)
   - ⚠️ **국물은 내솥 최대선 아래**, 재료 자작하게.
6. **찜/갈비찜 모드 25~30분.**
7. ⭐ **자동 감압 시작 전에 취소/전원 끄고 → 자연감압 10~15분** (분출 참사 방지!). 압력핀 내려가고 김 안 나면 뚜껑 열기.
8. 뚜껑 열고 **양파·표고·대파** 넣고, 뚜껑 연 채 5~10분 졸여 윤기 내기. 밤·대추는 이때.
9. 간 보고 부족하면 간장, 단맛 부족하면 설탕/물엿.

---

## TIP
- 어르신용은 **더 부드럽게** — 압력 시간 5분 더, 무는 푹 익혀 달게.
- **하루 전 만들어 식히면** 기름 굳어 걷기 쉽고 + 맛 더 배임.
- 아이도 같이 먹으면 청주·생강 줄이고 설탕 살짝 늘리기.
- 국물 자박하게 남겨 밥 비벼 먹으면 별미.

## 🥩 사태·양지로 갈비찜 (갈비 대용, 900g 기준) + 📅 전날 미리 버전 ⭐
> 갈비 품절이거나 담백하게 할 때. **사태 = 갈비 느낌(힘줄 젤라틴)**, 양지 = 씹는 맛·감칠맛. 섞으면 좋음.
> 👴 **80세 어르신이면 사태 비중 높이기**(더 부드러움), 양지는 얇게 썰기.

### 재료 (사태+양지 900g)
| 재료 | 분량 |
|------|------|
| 사태 + 양지 | 900g (사태 위주 추천) |
| 무 1/2개 · 당근 1개 · 양파 1개 · 대파 1대 · 표고 3~4개 | |
| 양념장 | 간장 7큰술 · 설탕 2.5 · 물엿 1 · 배즙 1/3개 · 마늘 1.5 · 생강 1작은술 · 청주 2 · 참기름 1 · 후추 · 물/육수 2컵 |
> 900g이라 위 기본(1kg)보다 양념 살짝 늘림. **닭육수로 하면 감칠맛↑**(간 된 육수면 물 섞어 희석).

### 조리 (사태·양지는 갈비보다 시간 더!)
1. **핏물 빼기** 1~2h → 큰 덩어리는 **7~10cm로 나눠** 담그기
2. **데치기** 5~7분 → 버리고 헹구기
3. 양념장 + 무·당근 + 고기 → 압력밥솥 (자작, **900g이니 최대선 확인**)
4. **찜/갈비찜 30~35분** (사태 힘줄·양지 무르게 갈비보다 길게) + **자연감압 15분**
5. 뚜껑 열고 양파·표고·대파 넣고 졸이기 — *단, 전날 할 거면 아래 참고*

### 📅 전날 미리 하는 법 (강추 — 맛↑·기름↓·당일 편함)
**전날:**
1. 위 1~4번까지 (고기+무·당근+양념 압력조리)까지만 → **식혀서 냉장**
2. 양파·표고·대파·밤·대추는 **넣지 말고 당일에** (전날 넣으면 물러짐)

**당일:**
3. 냉장한 것 → **위에 하얗게 굳은 기름 걷어내기** ⭐ (담백·어르신 좋음)
4. **약불로 데우면서** → 양파·표고·대파(+밤·대추) 넣고 5~10분 졸여 윤기
5. 국물 졸았으면 물 조금, 간 확인 (부족하면 간장/설탕)
6. **약불로 살살** 데우기 (센불이면 고기 부서짐)

> **왜 전날이 좋나:** ① 하룻밤 양념 배어 **맛 깊어짐** ② 굳은 기름 걷어 **담백** ③ 당일 데우기만 → 여유
> **보관:** 냉장 2~3일 (완전히 식혀 밀폐)
> **어르신 팁:** 사태 위주 + 압력 시간 넉넉히 + 얇게 썰어 담기 (양지는 결 반대로 얇게)
