# 매운 어묵볶음 (오뎅볶음)

> 매콤달콤 어묵볶음. **양념(고추기름) 먼저 볶고 → 어묵은 마지막에 살짝!**
> 어묵은 이미 익은 거라 오래 볶으면 질겨짐. 2~3인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 어묵 | 200g |
| 양파 | 1/2~1개 |
| 대파 | 1대 |
| 식용유 | 1큰술 |

### 양념
| 재료 | 분량 |
|------|------|
| 고추장 | 1큰술 |
| 고춧가루 | 1큰술 |
| 간장 | 1큰술 |
| 설탕 | 1큰술 (양파 캐러멜하면 줄이기) |
| 물엿(올리고당) | 1큰술 |
| 다진 마늘 | 0.5큰술 |
| 물 | 3~4큰술 |
| (마무리) 참기름·깨 | 약간 |

---

## 만드는 법 (순서 중요!)
1. **어묵 준비** — 먹기 좋게 썰어 **뜨거운 물 부어 기름기 빼기** (깔끔·잡내↓)
2. **양파 볶기** — 기름에 양파 볶기
   - 살짝만: 중약불 5~7분 (투명·살짝 단맛)
   - **캐러멜(덜 익은 느낌 싫으면)**: 약불 10~15분 갈색·달큰하게 ⭐ (눌어붙으면 물 조금)
3. **양념 볶기** — 양파에 **양념(고추장·고춧가루·간장·설탕·물엿·마늘·물) 넣고 중약불에 볶기**
   - 고춧가루·고추장이 **기름에 볶여 고추기름 나오게** (얼큰·감칠맛 핵심)
   - 약불로 살짝 (고추장 타지 않게)
4. **어묵 넣기 (마지막에!)** ⭐ — 어묵 넣고 **중불에 2~3분만** 볶아 양념 입히기
   - 이미 익었으니 오래 X (오래 볶으면 질기고 퍼져요)
5. **마무리** — 양념 배고 윤기 나면 대파·참기름·깨

---

## 🔑 핵심 포인트
- **순서: 양파 볶기 → 양념(고추기름) 볶기 → 어묵 마지막 2~3분** ⭐
- **어묵은 살짝만!** 이미 익어서 오래 볶으면 질기고 퍼짐
- 양파 **캐러멜라이징**하면 덜 익은 느낌 없고 깊은 단맛 (약불 10~15분)
  - 양파가 달아지니 → **설탕 줄이기**
- 어묵 **뜨거운 물에 데치기** → 기름·냄새 빼서 깔끔

## 🌶️ 매운맛 조절
- 순하게 → 고추장 위주, 고춧가루 줄이기
- 칼칼하게 → 청양고추 + 고춧가루 넉넉
- 아이도 → 고춧가루 줄이고 간장·고추장 베이스

## 💡 팁
- 물엿/올리고당 = 윤기 (마지막에 넣으면 더 반짝)
- 깻잎·당근·어묵꼬치 넣어도 굿
- 남으면 김밥 속·주먹밥에 활용
