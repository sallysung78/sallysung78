# 부추장 (부추 양념장)

> 부추+양파 다져 만드는 만능 양념장. 밥·수육·두부·고기구이·국수에 다 어울림.
> 밥에 참기름 뿌려 슥슥 비벼 먹어도 별미. (출처: 인스타 레시피)

---

## 재료
| 재료 | 분량 |
|------|------|
| 부추 | 100g |
| 양파 | 1/2개 |
| 양조간장 | 4T |
| 매실액 | 1T |
| 참기름 | 1T |
| 고춧가루 | 1T |

---

## 만드는 법
➡️ **부추와 양파를 잘게 다져 양념장(간장·매실액·참기름·고춧가루)과 섞으면 완성!**

- 먹기 전에 **참기름 더 뿌리면** 고소함↑

---

## 활용
- **밥에 비벼** — 참기름 두르고 슥슥 (밥도둑)
- **수육·보쌈·두부**에 찍먹/얹기
- **고기구이** 곁들임 양념
- **국수·비빔면** 양념
- 계란밥·두부덮밥에 올리기

## TIP
- 양파는 **찬물에 잠깐 담갔다** 빼면 매운맛↓ (순하게)
- 간장 짜면 → 물이나 매실액 조금 더
- 바로 먹어도 되고, **30분~1시간 두면** 간 배어 더 맛있음
- 냉장 2~3일 (오래 두면 부추 물러짐 → 조금씩 만들기)
