# 가지 솥밥

> 가지 + 다짐육 볶아 밥에 올려 지은 솥밥. 간장·참기름으로 슥슥 비벼 먹기.
> (출처: 인스타 레시피)

---

## 재료
| 재료 | 분량 |
|------|------|
| 쌀 | 2컵 (20분 이상 불려서) |
| 물 | 2컵에서 약간 적게 |
| 가지 | 2개 |
| 돼지고기 다짐육 (소고기 가능) | 200g |
| 야채가루 | 1포 |
| 양조간장 | 2T |
| 다진 마늘 | 1T |
| 맛술 | 1T |
| (마무리) 참기름 | 약간 |

---

## 만드는 법
1. **가지** 4등분 후 깍둑썰기
2. 기름 두른 냄비에 **돼지고기 볶다가 → 맛술 1T 넣어 잡내 잡고** → 가지 넣어 함께 볶기
3. **간장 2T 넣고 볶다가 → 접시에 덜어두기**
4. **불린 쌀 + 물 + 야채가루** 넣고 끓이다가 → 물 끓어오르면 **볶아둔 가지고기 넣고 약불 10분**
5. **불 끄고 10분 더 뜸들이면** 완성 → **먹기 전 참기름 뿌려** 비벼 먹기

---

## TIP
- **쌀 20분 이상 불리기** (솥밥은 불려야 고슬고슬)
- 물은 평소보다 **약간 적게** (가지·고기서 수분 나옴)
- 가지고기는 **밥 위에 올려** 지어야 밥이 질지 않음
- 다진 마늘은 고기 볶을 때 같이
- 참기름 + (송송 쪽파·깨) 마무리 → 향↑
- 소고기로 해도 OK
