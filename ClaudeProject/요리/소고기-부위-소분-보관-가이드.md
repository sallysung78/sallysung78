# 소고기 부위·소분·보관 가이드

> 부위 고르기 + 소분·손질 + 양념·냉동 타이밍을 한 장에. 정육점·주방에서 폰으로 바로 보기용.

---

## 1. 부위 가이드 (구이용 → 찜용 순서)

부드러운 살코기일수록 **구이**, 힘줄·결합조직 많을수록 **찜**.

### 🔥 구이용 (부드럽고 마블링)
| 부위 | 특징 |
|------|------|
| 안심 | 가장 부드러움. 최고급 스테이크 |
| 등심 | 부드럽고 고소. 구이·스테이크 대표 |
| 채끝 | 등심+안심 사이, 쫄깃+부드러움 |
| 살치살 | 마블링 폭발, 풍미 진함 |
| 부채살 | 가운데 힘줄 있음(빼면 부드러움) |
| 토시살·안창살 | 횡격막살, 쫄깃 고소 (희소부위) |
| 치마살 | 옆구리살. 기름·힘줄 적고 진한 맛, **쫄깃** |
| 차돌박이·우삼겹 | 얇게 썬 양지, 빠르게 구워 먹음 |

### ⚖️ 겸용 (구이·불고기·찜)
| 부위 | 특징 |
|------|------|
| 갈비 | 생갈비=구이 / 갈비찜=찜, 둘 다 명품 |
| 설도·우둔 | 기름 적은 살코기. 불고기·장조림·육회 |
| 홍두깨살 | 결 곱고 단단. 장조림 대표 |

### 🍲 찜·국용 (질기지만 푹 끓이면 부드러움)
| 부위 | 특징 |
|------|------|
| 양지 | 결 단단. 국물·수육·장조림 (감칠맛↑) |
| 사태 | 힘줄 많음 → 오래 끓이면 젤라틴화. 찜·탕·장조림 |
| 꼬리·도가니·우족 | 곰탕·도가니탕. 장시간 고기 |

```
부드러움 ←──────────────────────→ 질김(푹 끓이면 부드러움)
안심·등심·채끝 │ 살치살·부채살·치마살 │ 갈비·설도 │ 양지·사태 │ 꼬리·도가니
   ─── 구이 ───            ── 겸용 ──        ─── 찜·국 ───
```

---

## 2. 안심이 비쌀 때 — 살코기 대용 (기름·힘줄 싫을 때)

| 원하는 것 | 추천 | 비고 |
|------|------|------|
| **스테이크·구이** | **채끝** ⭐ | 가장자리 기름만 떼면 깔끔. 안심보다 저렴 |
| 불고기·장조림·육회 | 홍두깨·우둔 | 가장 저렴·순살코기. 구이엔 퍽퍽 |
| 구이인데 기름 싫음 | 토시살 | 기름·힘줄 없이 부드러움 (희소부위) |
| 쫄깃+진한 고기맛 | 치마살 | 살코기인데 풍미 좋음. **결 반대로 썰기** |

> **살코기 부드럽게 먹는 법**: 기름 적은 부위는 오래 익히면 퍽퍽 → **미디엄까지만** + **결 반대로 얇게 썰기** + 소금·후추는 굽기 직전.

---

## 3. 소분·손질법 (부채살 기준)

부채살은 **가운데 굵은 힘줄(떡심)**이 부챗살처럼 지나가는 게 특징.
```
   [살]  ═══ 힘줄(떡심) ═══  [살]
  부드러움      질김        부드러움
```

### 용도별 손질
1. **스테이크용** ⭐: 가운데 힘줄 따라 살을 발라 **2덩이로 분리** → 질긴 힘줄 제거 → 살을 **결 반대로 2cm** 썰기
2. **구이(불판)용**: 힘줄 살린 채 **힘줄과 수직으로 얇게(0.5cm)** 썰기 (얇아야 안 질김)
3. **스튜·찜용**: 힘줄째 깍둑 썰어 오래 끓이면 힘줄이 녹아 더 부드러움 (부르기뇽!)

### 겉지방·은막 처리
| 종류 | 처리 |
|------|------|
| 얇고 부드러운 겉지방 | 남겨도 OK (고소함) |
| 두껍고 단단한 지방 | 떼어냄 (안 녹고 느끼) |
| 은막(흰 막·근막) | 제거 (가열해도 질김) |
| 살 사이 마블링 | 그대로 (맛의 핵심) |

> **지방에 살 붙어 떨어지면** 버리지 말고 → 힘줄 자투리와 함께 모아 냉동 → 스튜·볶음·다짐육용.

## 4. 흰 부분 구분 — 지방 vs 힘줄

| | 지방(기름) | 힘줄·근막(콜라겐) |
|---|---|---|
| 모양 | 불투명 흰/크림색, 줄무늬 | 반투명·반질반질, 질긴 띠·막 |
| 만지면 | 무르고 기름짐 | 단단·쫄깃·고무 같음 |
| 가열하면 | **녹아서 기름** | **(오래) 젤라틴으로 변함** |

- **힘줄(떡심) = 콜라겐** → 물에 **오래 푹 끓이면(1~2시간) 도가니탕처럼 쫀득**해지고 국물도 진해짐.
  - 단, **촉촉하게(국물에) 오래** 끓여야 함. 짧게 굽거나 볶으면 그냥 질김.
- **지방**은 도가니처럼 안 됨 → 녹아서 기름. 느끼한 거 싫으면 제거.

## 5. 양념·보관 타이밍

### 양념은 "먹기 직전"에 (미리 X)
- **소금 미리 X**: 삼투압으로 수분 빠져 퍽퍽해지고 색 칙칙. (드라이브라인은 굽기 40분~24시간 전 얘기, 장기보관용 아님)
- 올리브유: 냉장 2~3일 단기면 코팅 OK / **냉동이면 안 바름**(산패 위험)
- → **소분은 양념 없이**, 구울 때 소금·후추·기름.

### 냉동 (며칠 넘게 둘 때)
1. 양념 없이 **한 끼 분량씩** 소분
2. **공기 빼고 밀착 포장** (랩 → 지퍼백, 가능하면 진공)
3. 날짜 적어 냉동, **~1개월 내 소비**
4. 먹을 때: **냉장 해동 → 물기 제거 → 그때 양념**

### 냉장 (1~2일 내)
- 밀폐 냉장, 구울 때 양념.

---

## 한 줄 요약
- **구울 거** → 안심·등심·채끝·살치살·치마살 (살코기·마블링)
- **끓일 거** → 양지·사태 (힘줄·콜라겐 → 푹 끓이면 부드러움)
- **부채살 힘줄** → 빼면 구이, 힘줄째면 찜(도가니처럼 쫀득)
- **소분은 양념 없이**, 소금은 굽기 직전.
