# 황태국 (곱게 갈아 진하게)

> 황태채를 갈아서 끓인 뽀얗고 진한 황태국. 두부·계란 듬뿍 넣으면 밥 없이도 든든.
> 들기름에 볶아 끓여 구수함↑. (출처: 인스타 레시피 @_avecu)

---

## 재료
| 재료 | 분량 |
|------|------|
| 황태채 | 80g |
| 감자 | 1개 |
| 대파 | 1대 |
| 두부 | 적당량 |
| 계란 | 1~2개 |
| 다진 마늘 | 1큰술 |
| 들기름 | 2스푼 |
| 액젓 | 간 맞춤용 |
| 후추 | 약간 |
| 물 | 500ml + 1L (아래 참고) |

---

## 만드는 법
1. **감자** 먹기 좋게 썰고, **대파** 쫑쫑 썰기
2. **황태채** 물에 한 번 가볍게 씻고 **10분 정도 불리기** → 물 약간 넣고 **믹서(바이타믹스)로 곱게 갈기**
3. 냄비에 **간 황태 + 들기름 2스푼 + 물 500ml** 넣고 **먼저 끓이기**
4. 여기에 **감자 + 다진 마늘 + 물 1L** 추가 → **뚜껑 덮고 10분 더 끓이기**
5. **액젓으로 간** 맞추고 → **두부·계란물·대파·후추** 넣고 완성

> 밥 없이 드실 거면 → **두부·계란 듬뿍** 넣으면 진짜 든든!

---

## TIP
- **황태를 곱게 갈아** 끓이면 국물이 **뽀얗고 진해요** (뼈까지 갈면 더 진함)
- **들기름에 볶듯 먼저 끓이기** = 구수함·감칠맛 핵심
- 간은 **액젓** (소금보다 감칠맛). 부족하면 소금 추가
- 계란물은 넣고 **바로 젓지 말고** 살짝 뒀다 풀기 (몽글하게)
- 콩나물·무 넣어도 시원함↑
- 해장·아침 속풀이로 딱 (황태는 간 보호·해독)
