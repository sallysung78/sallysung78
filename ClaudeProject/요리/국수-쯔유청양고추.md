# 국수 — 쯔유 + 청양고추 양념 찍먹

> 삶은 국수를 시원한 쯔유에, 청양고추 양념 곁들여 찍어 먹는 여름 별미.
> 붓카케/판모밀 느낌. 더운 날 입맛 없을 때 딱. 2~3인분.

---

## 재료
### 국수·국물
| 재료 | 분량 |
|------|------|
| 소면 또는 중면 | 3인분 (약 300g) |
| 쯔유 (농축) | 제품 기준 희석 |
| 얼음물 | 희석용 |

### 청양고추 양념 (찍먹 소스)
| 재료 | 분량 |
|------|------|
| 청양고추 | 2~3개 (송송) |
| 쯔유 | 4큰술 |
| 물 (찬물) | 4큰술 |
| 식초 | 1큰술 |
| 설탕 | 1작은술 |
| 무·양파 간 것 (선택) | 1큰술 |
| 와사비 (선택) | 약간 |

### 고명
쪽파, 김가루, 깨, 무순, 계란지단, 오이채

---

## 만드는 법
1. **쯔유 희석:** 제품 표기대로 (보통 쯔유 1 : 물 3~4). **차게** 준비, 얼음 동동.
2. **찍먹 소스:** 청양고추 송송 + 위 양념 섞기 → 매콤·새콤·달큰. 쯔유에 타 먹거나 따로 두고 찍먹.
3. **국수 삶기:** 소면 3~4분. 끓어오르면 **찬물 반 컵씩 2~3번** 부어가며(면 쫄깃). 다 삶으면 **찬물에 빡빡 헹궈 전분 제거** → 얼음물에 헹궈 사려두기.
4. 국수 한 입씩 사려 접시에 담고, **쯔유 + 청양 양념에 찍어/적셔** 먹기. 고명 곁들이기.

---

## TIP
- **면도 차갑게, 쯔유도 차갑게** — 여름엔 시원함이 생명.
- 아버님 매운 것 괜찮으시면 청양 넉넉히, 아니면 **따로 내서** 각자 조절.
- 계란지단·오이채·새우튀김 곁들이면 상차림 근사해짐.
- 남은 쯔유에 밥 말고 김가루 → 마무리 별미.
