# 사태 수육 — 도가니탕 보강 & 수육 야채찜

> 사태 한 번 푹 쪄두면 ① 도가니탕에 살코기 듬뿍 + ② 수육처럼 썰어 야채찜·간장소스 찍먹, 두 가지로.
> 한 번에 소분 냉동하면 평일에 편함.

---

> ## ⚠️ 전기압력밥솥 양 제한 — 꼭 읽기 (실패 경험 반영)
> - **한 번에 600g 이하만!** (그 이상 넣지 말 것)
> - 사태는 기름·젤라틴이 많아 국물에 두꺼운 거품층이 생기는데, **양이 많으면 압력 뺄 때 국물이 분출**해서 부엌이 난리남 + 아까운 육수가 다 넘침. (실제로 900g 넣었다가 솟구침 ㅠ)
> - **양이 많으면 → 전기압력밥솥 말고 일반 냄비에 나눠서 오래 끓이기.**
> - 압력 끝나면 **추 건드리지 말고 10~15분 자연감압** → 그래도 뺄 땐 추를 조금씩 살살.

---

## 재료
- **사태** (전기압력밥솥은 **한 번에 600g 이하** / 그 이상은 일반 냄비) — 기름 적고 푹 삶으면 부드러움 / 양지 섞어도 OK
- 향신채: 대파, 마늘, 양파, 통후추, (생강 한 쪽)
- (선택) 된장 1작은술 또는 청주 — 누린내 잡기
- 도가니탕 팩 (국물용)

---

## 1. 사태 찌기(삶기)

### ① 핏물 빼기 (누린내 핵심)
찬물에 **30분~1시간** 담가 핏물 빼기. 중간에 물 한 번 갈기.

### ② 데치기
끓는 물에 **5분 끓인 뒤 그 물 버리기** → 불순물·핏기 제거(국물 맑아짐).

### ③ 푹 익히기
새 물에 고기 + 향신채 넣고:
- **전기압력밥솥**: 만능찜/갈비찜/백숙 모드 **30~40분** ⭐ (⚠️ **고기 600g 이하 + 물은 최대선 아래**, 끝나면 **자연감압 10~15분**)
- **일반 냄비**: 약중불 **1시간~1시간 30분** (젓가락 쑥 들어가면 완성) — **양 많을 땐 이쪽 추천**

### ④ 식혀서 썰기 ★중요
건져서 **한 김 식힌 뒤 결 반대로** 썰기.
- **도가니탕용** → 얇게
- **수육용** → 약간 도톰하게
> 뜨거울 때 썰면 부서짐. **식혀야 모양 예쁨.**

> **흰 힘줄(반질반질) = 제거하지 말고 삶기** → 쫀득 젤라틴 + 부드러움·진한 국물. 아이가 살코기만 좋아하면 **썰 때 힘줄 부분만 골라내고** 살코기만 그릇에. (지방 큰 덩어리만 떼기, 사태는 지방 거의 없음)

---

## 2. 활용 A — 도가니탕에 넣어 먹기
```
도가니탕 팩 국물 데우기
 → 썬 살코기 듬뿍 넣고 같이 데우기 (국물맛 배어듦)
 → 소금·후추 간 + 송송 썬 대파·다진 마늘
 → 아이 그릇엔 살코기 많이!
```
> 삶은 국물도 버리지 말 것 — 팩 국물 보충하거나 다른 국·찌개 육수로.

---

## 3. 활용 B — 수육 야채찜 + 간장소스 찍먹

### 야채찜
한입 크기로 썰어 **찜기/냄비/전자레인지**로 부드럽게 찌기:
- 양배추·알배추, 애호박, 당근, 브로콜리, 단호박, 버섯 등 (있는 야채)
- 전자레인지면 그릇에 담고 물 살짝 + 뚜껑/랩 → 3~5분
- 사태 수육 + 찐 야채를 소스에 찍어 먹기 (담백·건강)

### 간장베이스 소스 (택1)
**① 기본 간장소스**
- 간장 2 + 물 1 + 식초 1 + 올리고당(설탕) 0.5
- 다진 마늘 약간 + 송송 청양고추 + 참기름·깨

**② 머스터드 간장 (냉장고 홀그레인 머스터드 활용)** ⭐
- 간장 2 + **홀그레인 머스터드 1** + 올리고당 1 + 식초 1
- 수육·찐야채에 톡 쏘면서 잘 어울림

**③ 정통 수육 스타일**
- 간장 + 연겨자 + 식초 + 설탕 (새우젓 곁들이면 더 정통)

> 라임액 있으면 식초 대신 **라임액**으로 상큼하게 변형 가능.

## 4. 대량으로 해두기
1. 삶아서 **결 반대로 썰기** (압력솥이면 **600g씩 나눠서** 여러 번)
2. **한 끼분씩 소분 → 냉동** (몇 주 OK)
3. 먹을 때 도가니탕 국물에 데우거나, 살짝 쪄서 수육으로
> 고기는 식혀 썰어 **국물 살짝 적신 통**에, **국물은 따로** 보관 → 둘 다 더 오래가고 활용 편함.

---

## 🥩 국물 넉넉 + 고기 부드럽게 (작은 밥솥 분리 공식) ⭐
> 6인 밥솥은 국물이 적게 나옴. **"부드러운 고기"와 "진한 고기국물"은 상충** (고기맛이 국물로 빠지면 고기 퍽퍽) → **국물용/먹는용을 나누는 게** 답.

**핵심 원리**
- 냄비(오래) = 촉촉·쫄깃·국물 넉넉 / 압력밥솥(짧게) = 확 부드러움·국물 적음
- 고기 나중에 잠깐만 넣으면 → **국물에 고기맛 약함** (감칠맛은 오래 끓여야 우러남)

**양지 + 부채살 힘줄 실전 플랜 (양지 600g 기준)**
1. **냄비 = 힘줄 국물** (먼저 시작·오래): 부채살 힘줄(떡심) + 향신채(대파·양파·마늘·통후추·**무 한토막**) + 물 **2~2.5L** → 약불 **2~3시간** (힘줄이 도가니처럼 물러지고 국물 진해짐, 거품 걷어 맑게)
   - ★ 부채살 떡심(흰 힘줄) = 콜라겐 → 오래 끓이면 **젤라틴으로 녹아 도가니처럼 쫀득**. 단 살코기보다 훨씬 오래(밥솥 40분~1시간 / 냄비 2~3시간).
2. **밥솥 = 양지 살코기** (짧게·부드럽게): 핏물빼기→데치기→헹구기 → 양지 600g + 물 자작 + 향신채 → 만능찜 **30~40분 + 자연감압 15~20분** → **국물에 담가둬야 촉촉 유지**
3. **합치기**: 힘줄 국물에 양지+국물 넣고 **약불 10~15분**만 (데우고 어우러질 정도, **양지 오래 끓이면 퍽퍽!**) → 마지막에 소금·후추 간
   - **양지는 통째로 데운 뒤 → 한 김 식혀 결 반대로 썰기** (얇게 썰어 끓이면 육즙 빠지고 질김 / 뜨거울 때 썰면 부서짐). 썬 양지를 그릇에 담고 국물 붓기.

**밥솥에 양지+힘줄 같이 하려면?** 익는 시간 달라 → **만능찜 40~45분 + 자연감압 길게**로 타협 (양지 좀 물러도 아이 살코기용엔 OK). 국물 넉넉히는 별도 냄비 육수.

**👶 아이 살코기:** 힘줄째 삶아 맛 내고 → 먹일 때 **살코기만 골라** 아이 그릇에. 간은 **아이 것 먼저 덜고** 어른용 세게.

## TIP
- ⚠️ **압력밥솥은 600g 이하!** 많이 넣으면 감압 때 국물 분출(부엌 난리·육수 유실). 양 많으면 일반 냄비.
- 국물용 육수: 향채 야채육수 + **양지육수 섞으면** 더 깊음 (야채육수 2 : 양지육수 1, 소금은 마지막에)
- 데칠 때 핏물이 좀 나와도 정상 — 더 데치면 육즙만 빠짐. **본삶기 초반 거품(스컴)만 걷어내면** 국물 맑아짐.
- 더 부드럽게: **전기압력밥솥 만능찜**이 제일 편하고 부드러움 (단, 소량일 때)
- 누린내: 핏물 빼기 + 데치기 + (된장/청주) 3단계면 충분
- 식은 수육은 **살짝 쪄서/데워서** 내면 부드러움 (찬 채로보다 맛↑)
- 흰 힘줄 = 삶는 요리엔 보약. 아이용은 살코기만 골라주기.
