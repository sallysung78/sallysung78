# 미역 소고기 요리 (미역국 말고!)

> 미역 = 혈액순환·철분·요오드 풍부. 미역국 말고도 활용 많음.
> **양지·사태 삶은 것 + 국물**로 반찬·한 끼 뚝딱. 미역만 쓰는 반찬도 포함.

---

## 🌿 미역 다루기 (공통)
- **마른 미역은 물에 20~30분 불리기** → 헹궈 짠기·미끈함 빼기
- 불리면 **7~10배로 불어남** → 조금만 사용 (한 줌이면 넉넉)
- 미역은 **금방 익음** → 오래 안 끓여도 됨

---

## 🥩 양지·사태 + 미역

### 1. 미역 소고기볶음 ⭐ (반찬 추천)
| 재료 | 분량 |
|------|------|
| 불린 미역 | 2컵 |
| 삶은 양지/사태 | 150g (채썰기) |
| 들기름(참기름) | 1큰술 |
| 국간장 | 1큰술 |
| 다진 마늘 | 0.5큰술 |
| 깨·후추 | 약간 |

**만들기:** 들기름에 고기·마늘 볶기 → 미역 넣고 볶기 → 국간장으로 간 → 물 조금 넣고 자작하게 볶다 깨. (밑반찬으로 든든·고소)

### 2. 미역 소고기죽 (한 끼·보양)
- 사태/양지 **국물** + 잘게 썬 고기 + 불린 미역 + 밥 → 푹 끓여 죽
- 참기름·국간장·깨 → 소화 잘되고 든든. 어르신·아이 좋음.

### 3. 미역 소고기 초무침 (여름 반찬)
- 데친 미역 + 삶은 양지 채 + 초고추장(또는 간장+식초+설탕) → 새콤 무침. 입맛 살림.

### 4. 미역 소고기 냉국 (여름)
- **양지 육수 차게** + 불린 미역 + 오이채 + 국간장·식초·설탕 → 시원한 냉국. (국수 말아도 굿)

---

## 🌱 미역만으로 (고기 없이 반찬)
- **미역 오이 초무침** — 데친 미역 + 오이 + 식초·설탕·고춧가루·마늘 → 여름 새콤 반찬
- **미역줄기 볶음** — 미역줄기 + 마늘 들기름에 볶기 (밑반찬 국룰)
- **미역 참기름 무침** — 데친 미역 + 간장·참기름·깨 → 간단 무침
- **미역쌈** — 데친 미역에 밥·쌈장 싸 먹기

---

## 🎯 추천
- **양지·사태 있으면 →** 미역 소고기볶음(반찬) or 미역 소고기죽(한 끼)
- **삶은 고기·국물 활용** 좋음 (남은 수육·도가니탕 국물 등)

## TIP
- 미역 짠맛 강하면 → 불릴 때 물 갈아가며 헹구기
- 볶음은 **들기름**이 고소함 최고 (참기름도 OK)
- 국간장으로 간해야 깔끔 (진간장은 색 진해짐)
- 초무침은 **먹기 직전** 무쳐야 물 안 생김
