# 부추 새우전 (전분 ver.)

> 부추 + 새우 + 전분으로 바삭·쫀득한 전. 밀가루 없이 전분만으로도 OK!
> 얼큰한 육개장·국물요리에 담백하게 곁들이기 딱. 2~3인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 부추 | 한 줌 (송송 3~4cm) |
| 새우 | 6~8마리 (굵게 다지기) |
| 전분가루 | 1/2~1컵 |
| 물 | 전분과 비슷한 양 (되직하게) |
| 계란 (선택) | 1개 (더 폭신·고소) |
| 소금 | 약간 |
| 식용유 | 넉넉히 |

### 곁들임
- 초간장 (간장 1 + 식초 1 + 물 조금, 청양고추·깨)

---

## 만드는 법
1. **부추** 송송(3~4cm), **새우** 굵게 다지기 (탱글하게, 너무 곱게 X)
2. **반죽** — 전분 + 물 + (계란) + 소금 조금 → **되직하게** (흐르지 않을 정도)
3. 부추·새우 넣고 섞기 (넣고 **바로 부치기** — 부추 물 나옴)
4. 기름 두른 팬에 **얇게 펴서 중불로 노릇하게** 양면
5. 초간장 찍어 먹기

---

## TIP
- **전분만 쓰면** 밀가루보다 **더 바삭·쫀득** (약간 투명하게 부쳐짐, 과자처럼)
- 반죽 **되면 물 / 묽으면 전분** 추가로 농도 조절
- **기름 넉넉히 + 중불** → 바삭하게
- 계란 넣으면 폭신·고소 (없어도 OK)
- 식으면 살짝 질겨짐 → **따뜻할 때** 먹기
- 부추는 물 많이 나오니 → 반죽에 넣고 바로 부치기

---

## 🍲 육개장 상차림 (추천 조합)
```
육개장 + 부추 새우전 + 깍두기(or 무생채) + 밥
```
→ 얼큰(육개장) + 바삭담백(전) + 아삭시원(깍두기) = 밸런스 완벽

**육개장과 어울리는 다른 반찬:** 깍두기·무생채·오이무침·콩나물무침·계란찜·김·장아찌 (진한 국물엔 개운한 반찬)
