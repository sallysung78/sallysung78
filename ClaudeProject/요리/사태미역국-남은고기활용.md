# 미역국 (삶은 사태 + 남은 국물 활용, 초간단)

> 어제 끓인 사태 편육 + 소고기 국물로 20분 뚝딱. 육수 낼 필요 없어 간편.
> 이미 소고기 육수라 진하고 맛있음. 아빠 미역국으로 딱! 3~4인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 삶은 사태 (편썬 것) | 있는 만큼 |
| 어제 소고기 국물 | 있는 만큼 (+ 물 보충) |
| 불린 미역 | 한 줌 (불리면 7~10배) |
| 들기름(참기름) | 1~2큰술 |
| 국간장 | 1~2큰술 |
| 다진 마늘 | 0.5~1큰술 |
| 소금·후추 | 마지막 간 |

---

## 만드는 법
1. **미역 손질** — 20~30분 불리기(급하면 10분) → **바락바락 씻어** 물기 짜기 (미끈함↓)
2. **미역 볶기 ⭐ (맛의 핵심)** — 냄비에 들기름 두르고 **미역 + 다진 마늘** 넣고 **중불~중강불로 2~3분** 볶기 (고소함↑)
3. **국물 붓기** — 어제 국물 붓기(기름 떴으면 걷고) + **사태 편육** 넣기 + 물 부족하면 추가
4. **끓이기** — 국간장으로 간, **약중불 15~20분** (미역 부들부들해질 때까지)
5. **마지막 간** — 국간장·소금·후추로 조절

---

## 🔑 포인트
- **미역을 들기름에 볶기** = 미역국 맛의 8할 (안 볶으면 밍밍)
- **어제 국물** = 이미 사태 감칠맛 우러난 육수 → 미역국 국물로 완벽
- **사태 편육** = 이미 익었으니 넣고 데우면 됨 (오래 X)
- 편육 질겼으면 → **더 얇게 썰어** 넣기 (국물에서 더 부드러워짐)

## ⚠️ 체크
- 어제 국물은 **냉장 보관한 것**만! (실온 밤새면 상함) → 데워서 냄새 확인
- 국물 진하거나 간 돼 있으면 → 물 넣어 희석 + 간 조절
- 국물 부족하면 → 물 + 분말육수/다시다 조금
- 소금은 **마지막에** (일찍 넣으면 졸며 짜짐)
