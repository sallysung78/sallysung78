# 미역국 (시판 갈비탕 활용, 간편 버전)

> 육수 낼 필요 없이 시판 갈비탕(국물+고기)으로 뚝딱. 고기까지 활용.
> **핵심: 미역+고기를 참기름에 먼저 볶기!** 2~3인분.

---

## 재료
| 재료 | 분량 |
|------|------|
| 마른 미역 | 한 줌 (불리면 7~10배) |
| 시판 갈비탕 | 1팩 (국물 + 고기) |
| 참기름(들기름) | 1큰술 |
| 국간장 | 1~2큰술 |
| 다진 마늘 | 0.5~1큰술 |
| 물 | 국물 부족하면 추가 |

---

## 만드는 법
1. **미역 불리기** — 물에 20~30분 → 헹궈 짠기·미끈함 빼고 물기 짜기 (**조금만! 7~10배로 늘어남**)
2. 미역 먹기 좋게 썰기
3. **미역+고기 볶기 ⭐ (맛의 핵심)** — 냄비에 참기름 두르고 갈비탕 고기 + 미역 + 다진 마늘 넣고 **3~5분 볶기** (고소함·감칠맛↑)
4. **갈비탕 국물 붓기** (부족하면 물 추가)
5. **끓이기** — 국간장으로 간, **약중불 15~20분** (미역 부들부들해질 때까지)
6. 간 보고 소금·국간장 조절

---

## 🔑 맛 포인트
- **미역+고기를 참기름에 먼저 볶기** = 미역국 맛의 핵심! (안 볶으면 밍밍)
- **국간장으로 간** (소금만보다 감칠맛)
- 갈비탕이 이미 간 돼 있으니 → **물 추가하며 간 조절** (짜면 물, 싱거우면 국간장)
- 오래 끓일수록 미역 부들부들·국물 진해짐

## 💡 팁
- 갈비탕 국물 적으면 → 물·멸치육수 추가
- 갈비탕 간 세면 → 물 넉넉히 + 간 맞추기
- 다진 마늘 꼭! (감칠맛)
- 들기름이 참기름보다 더 구수 (취향)
- 갈비탕 고기 뼈 있으면 → 살 발라 넣거나 뼈째(국물맛↑)
- 미역 불릴 때 물 갈아 헹구면 짠맛·비린내↓
