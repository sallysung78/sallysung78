# 김치 돼지고기찜 (묵은지찜)

> 푹 익은 김치 + 돼지고기를 오래 쪄낸 밥도둑. 어르신·아이 다 좋아함.
> 묵은지가 있으면 최고. 4인분.

---

## 재료
### 메인
| 재료 | 분량 |
|------|------|
| 묵은지(신김치) | 1/2포기 |
| 돼지고기 (목살·앞다리·삼겹 통) | 600g |
| 양파 | 1개 |
| 대파 | 1대 |
| 두부 (선택) | 1모 |

### 국물·양념
| 재료 | 분량 |
|------|------|
| 김치 국물 | 1컵 |
| 물 또는 멸치육수 | 2~3컵 |
| 고춧가루 | 1큰술 |
| 다진 마늘 | 1큰술 |
| 국간장 | 1큰술 |
| 설탕 | 1작은술 (신맛 조절) |
| 들기름 또는 식용유 | 1큰술 |

---

## 만드는 법
1. 냄비에 들기름 두르고 **김치를 5분 볶기** (군둥내 날리고 감칠맛↑). 고춧가루·설탕 넣고 더 볶기.
2. 돼지고기(통째 또는 큼직하게)와 양파 넣고 **김치국물 + 물/육수** 자작하게 붓기. 다진 마늘·국간장 넣기.
3. 뚜껑 덮고 **약불 40분~1시간** 뭉근히 (묵은지·고기 다 무를 때까지).
   - 압력밥솥이면: 찜 모드 20~25분 + **자연감압**.
4. 고기 건져 **먹기 좋게 썰어** 다시 넣고, 두부·대파 얹어 10분 더.
5. 간 보고 싱거우면 국간장/새우젓, 신맛 강하면 설탕 조금.

---

## TIP
- **고기는 통으로 삶아 썰면** 육즙 유지 + 수육처럼 부드러움. 어르신은 목살(부드럽고 기름 적당) 추천.
- 김치가 덜 익었으면 식초 살짝 or 김치국물 더 넣어 신맛 보강.
- **하루 전 만들면** 더 깊은 맛.
- 삶은 사태·수육 남은 것 있으면 함께 넣어도 좋음.
