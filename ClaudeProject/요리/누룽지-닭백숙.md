# 누룽지 닭백숙 (전기밥솥 한 번에)

> 밑에 찹쌀 깔고 닭 얹어 전기밥솥 한 번에! 바닥은 누룽지, 위는 백숙.
> 밥솥 하나로 국물+누룽지 동시 해결. (출처: 인스타 레시피)

---

## 재료
| 재료 | 분량 |
|------|------|
| 찹쌀 | 밥그릇 하나 정도 (안 불려도 됨) |
| 닭다리살 or 닭다리(북채) | 적당량 |
| 대파·양파·마늘·대추·통후추 | 적당량 |
| 간장 | 2숟갈 |
| 소금 | 쪼끔 |
| (선택) 맛술·미림 | 안 넣어도 됨 |
| 물 | **국물 있게 500ml / 꾸덕하게 300ml** ⭐ |

---

## 만드는 법
1. **찹쌀** 밥그릇 하나 정도 씻어 **밥솥 바닥에 깔기** (안 불려도 됨)
2. **닭다리살(or 닭다리)** 위에 깔기
3. **파·양파·마늘·대추·통후추** 넣기
4. **간장 2숟갈 + 소금 쪼끔** (맛술·미림은 선택)
5. **★ 물 포인트:** 국물 필요하면 **500ml**, 꾸덕하게(누룽지죽처럼) 먹고 싶으면 **300ml**
6. **만능찜 모드 80분** 설정 → 렛츠고! (오래 해야 누룽지가 아주 맛나게 됨)

---

## ⚠️ 핵심 포인트
- **⏱️ 만능찜 80분** — 길게 해야 바닥이 **누룽지**로 눌어붙어 맛있어짐 ⭐
- **물 양으로 조절:** 국물 백숙 = 500ml / 꾸덕한 누룽지죽 = 300ml
- **재료가 밥솥에 꽉 차면 안 됨!** (넘침 방지 — 여유 있게)
  - 원본은 10인용 밥솥 기준, 전혀 안 넘쳤다고 함
  - ⚠️ 6인 등 작은 밥솥이면 **양 줄이기** (특히 찹쌀·물)
- 찹쌀 **안 불려도 OK** (80분 오래 하니 익음)

## TIP
- 소금은 심심하게 → 먹을 때 각자 간 / 양념장(부추장·마늘간장) 찍먹
- 다 되면 **자연감압** (밥솥 만능찜 후) → 뚜껑 열기
- 바닥 누룽지 눌어붙었으면 → 주걱으로 슥슥 긁어 국물이랑
- 닭다리살이 발라먹기 편함 (뼈 없음), 북채는 뼈째 국물맛↑
- 대추·마늘 넉넉히 = 삼계탕 느낌
- ※ 국물 넉넉한 삼계탕은 → `삼계탕.md`, 넘침 방지 상세는 → `닭북채-찹쌀백숙.md`
