# 닭북채 찹쌀 백숙 (압력밥솥) — 넘침 방지 버전

> 닭다리 북채 + 찹쌀 깔고 압력밥솥으로 부드러운 백숙.
> **핵심: 넘침 방지 + 자연감압.** 3~4인분.
> 참고 출처(직접 확인 못 함): 네이버 블로그 chzh10000 (logNo 223953590244)

---

## 재료 (3~4인분)
| 재료 | 분량 |
|------|------|
| 닭북채(드럼스틱) | 6~8개 (800g~1kg) |
| **찹쌀** (또는 현미찹쌀) | 1/2~1컵 (꼭 불려서) |
| 마늘 | 8~10쪽 |
| 대파 | 1대 |
| 양파 | 1/2개 |
| 생강 | 1쪽 |
| (선택) 황기·대추·통후추·수삼 | 적당량 |
| 물 | 재료 80% 잠길 정도 (**최대선 아래**) |
| 소금·후추·부추(파) | 마무리 |

---

## 🚨 넘침 방지 핵심 5가지 (제일 중요!)
1. **찹쌀 불리기** ⭐ — 불리면 물 덜 먹고 전분 거품 줄어 넘침 방지 (백미찹쌀 30분~1시간 / **현미찹쌀 2~3시간+**)
2. **닭 데치기** — 끓는 물 3~5분 데쳐 핏물·기름·거품 제거 (**거품이 넘침 주범**)
3. **물은 최대선 훨씬 아래** — 찹쌀이 물 먹고 부푸니 자작하게 (재료 80% 잠길 정도)
4. **찹쌀 양 적당히**(1/2~1컵) — 많으면 압력추 막힘·바닥 눌어붙음
5. **⭐ 자연감압** — 찹쌀 전분 국물은 급속감압하면 분출! 자동 김빼기 전 취소 → 15~20분 자연감압

---

## 만드는 법
1. **찹쌀 불리기** → 헹궈 물기 빼기
2. **북채 데치기** 3~5분 → 버리고 헹구기
3. 내솥 바닥에 **불린 찹쌀 깔기** → 그 위에 **북채 + 마늘·대파·양파·생강** (+약재)
4. **물 붓기** — 재료 80% 잠길 정도, **최대선 아래 확인** ✅
5. **찜/백숙 모드 20~25분** (현미찹쌀은 25~30분)
6. **자연감압 15~20분** (급속 X) → 압력핀 내려가면 뚜껑
7. 뚜껑 열고 **소금·후추 간**, 송송 파·부추 곁들임

---

## 🌾 현미찹쌀 버전 (조정 2가지)
현미찹쌀로 해도 OK! 백미찹쌀과 성질이 달라 아래만 조정:
1. **불리기 훨씬 길게** — 껍질(쌀겨) 있어 물 잘 안 먹음 → **최소 2~3시간, 가능하면 반나절~하룻밤**. (안 불리면 속 설익어 오독오독)
2. **압력 시간 +5분** — **25~30분** (현미가 덜 익음)
- ✅ 넘침은 오히려 **덜 위험** (전분 거품이 백미보다 적음)
- 식감: 오독오독·구수, 식이섬유·영양↑ / 소화는 살짝 거침
- 👴 **어르신·소화 약하면:** 더 푹 익히거나 **백미찹쌀과 반반** 섞기 (부드러움+구수함)

---

## ⚠️ 찹쌀 바닥 눌어붙음 방지
- **바닥에 물이 꼭 깔리게** (마른 찹쌀이 바닥에 직접 닿으면 눌어붙음)
- 💡 **더 확실한 법:** 불린 찹쌀을 **면포/다시백에 넣어** 바닥에 두기 → 눌어붙음·추 막힘 없이 **찰밥 덩어리**로 나옴 (백숙집 방식, 서빙 깔끔)

---

## TIP
- 데치기 + 향신채(대파·마늘·생강)면 닭 잡내 충분히 잡힘
- 국물 진하게: 황기·대추 넣고 끓이면 삼계탕 느낌
- 남은 국물 + 찰밥 → **닭죽**으로 마무리 별미
- 소금은 **먹기 직전 각자 찍어** 먹어도 좋음 (심심하게 끓여서)
