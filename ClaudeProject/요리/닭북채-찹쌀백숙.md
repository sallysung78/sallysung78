# 닭북채 찹쌀 백숙 (압력밥솥) — 넘침 방지 버전

> 닭다리 북채 + 찹쌀 깔고 압력밥솥으로 부드러운 백숙.
> **핵심: 넘침 방지 + 자연감압.** 3~4인분.
> 참고 출처(직접 확인 못 함): 네이버 블로그 chzh10000 (logNo 223953590244)

---

## 재료 (3~4인분)
| 재료 | 분량 |
|------|------|
| 닭북채(드럼스틱) | 6~8개 (800g~1kg) |
| **찹쌀** (또는 현미찹쌀) | 1/2~1컵 (꼭 불려서) |
| 마늘 | 8~10쪽 |
| 대파 | 1대 |
| 양파 | 1/2개 |
| 생강 | 1쪽 |
| (선택) 황기·대추·통후추·수삼 | 적당량 |
| 물 | 재료 80% 잠길 정도 (**최대선 아래**) |
| 소금·후추·부추(파) | 마무리 |

---

## 🚨 넘침 방지 핵심 5가지 (제일 중요!)
1. **찹쌀 불리기** ⭐ — 불리면 물 덜 먹고 전분 거품 줄어 넘침 방지 (백미찹쌀 30분~1시간 / **현미찹쌀 2~3시간+**)
2. **닭 데치기** — 끓는 물 3~5분 데쳐 핏물·기름·거품 제거 (**거품이 넘침 주범**)
3. **물은 최대선 훨씬 아래** — 찹쌀이 물 먹고 부푸니 자작하게 (재료 80% 잠길 정도)
4. **찹쌀 양 적당히**(1/2~1컵) — 많으면 압력추 막힘·바닥 눌어붙음
5. **⭐ 자연감압** — 찹쌀 전분 국물은 급속감압하면 분출! 자동 김빼기 전 취소 → 15~20분 자연감압

---

## 만드는 법
1. **찹쌀 불리기** → 헹궈 물기 빼기
2. **북채 데치기** 3~5분 → 버리고 헹구기
3. 내솥 바닥에 **불린 찹쌀 깔기** → 그 위에 **북채 + 마늘·대파·양파·생강** (+약재)
4. **물 붓기** — 재료 80% 잠길 정도, **최대선 아래 확인** ✅
5. **찜/백숙 모드 20~25분** (현미찹쌀은 25~30분)
6. **자연감압 15~20분** (급속 X) → 압력핀 내려가면 뚜껑
7. 뚜껑 열고 **소금·후추 간**, 송송 파·부추 곁들임

---

## 🌾 현미찹쌀 버전 (조정 2가지)
현미찹쌀로 해도 OK! 백미찹쌀과 성질이 달라 아래만 조정:
1. **불리기 훨씬 길게** — 껍질(쌀겨) 있어 물 잘 안 먹음 → **최소 2~3시간, 가능하면 반나절~하룻밤**. (안 불리면 속 설익어 오독오독)
2. **압력 시간 +5분** — **25~30분** (현미가 덜 익음)
- ✅ 넘침은 오히려 **덜 위험** (전분 거품이 백미보다 적음)
- 식감: 오독오독·구수, 식이섬유·영양↑ / 소화는 살짝 거침
- 👴 **어르신·소화 약하면:** 더 푹 익히거나 **백미찹쌀과 반반** 섞기 (부드러움+구수함)

## 🍚 밥·누룽지 활용 (누룽지백숙)
### 현미찹쌀 안 불렸을 때
- **① 생 현미찹쌀을 닭이랑 한 번에 압력 ⭐ (제일 간단)** — 밥 따로 안 짓고 닭+현미찹쌀+물(넉넉)+향신채 → 찜 **30~35분** + 자연감압. 한 솥에 끝.
- **② 현미밥 먼저 지어서 깔기** — 안 불려 설익을까 걱정되면 현미밥(고슬하게) 먼저 짓고 바닥에 깔기. **압력 후 뚜껑 열고** 넣어 약불 5~10분 (익은 밥은 또 압력 X → 완전 죽 됨).
- **③ 설익은 밥(예: 30분만 지은 것)** — 닭이랑 넣고 **백숙 압력 20~25분** 돌리면 그때 마저 익음 → 누룽지죽처럼 걸쭉.

### 바삭 누룽지(말린 것) 넣기
- **⭐ 마지막에!** 압력 다 끝나고 뚜껑 열어 → 누룽지 넣고 **약불 5~10분** → 국물 먹으며 구수한 누룽지 향 살아남.
- ⚠️ 처음부터 압력에 넣으면 **완전 죽처럼 풀어지고 향·식감 사라짐** → 넣는 의미 없어짐.
- 밥·찹쌀 이미 넣었으면 누룽지는 **조금만** (뻑뻑해짐). 국물 넉넉히.

## 🍲 국물 깔끔하게 — 육수 미리 내기 / 다시백
- **육수 미리 내기:** 새 물 + 대파·양파·마늘·통후추·생강 20~30분 끓여 → **체에 걸러** 맑은 육수만 → 이걸로 백숙. **건더기 안 떠다녀 깔끔** (백숙집 방식).
- **간단 버전:** 향신채를 **면포/다시백에 넣어** 닭이랑 같이 압력 → 끝나고 **주머니째 건져내기** (한 솥에 끝, 건더기 없음).
- ⚠️ **데친 물은 육수로 쓰면 안 됨** — 핏물·잡내라 무조건 버리기.

## 🐔 데치기 정리
- 끓는 물 **3~5분** (겉 하얗게 + 거품 올라오면 완료). 속까지 안 익혀도 됨(압력에서 익음).
- 데친 뒤 **닭은 따뜻한 물에 헹구고**(찬물은 수축), **데친 물은 버리기**.
- 목적 = 핏물·기름·거품 제거 → **넘침 방지 + 맑은 국물**. 오래 데치면 육즙만 빠짐.

## 🥢 찍먹 양념장 (택1)
백숙은 심심하게 끓여 **양념장에 찍어** 먹는 게 정석. (간은 완성 후 or 각자 찍먹)

**① 부추 간장양념장 ⭐ (백숙 국룰)**
- 간장 3 + 식초 1 + 고춧가루 1 + 다진 마늘 0.5
- **송송 썬 부추** 넉넉히 + 참기름·깨
- (선택) 청양고추 + 백숙 국물 1큰술
- → 부추 향이 닭이랑 찰떡, 누린내도 잡아줌

**② 양파 간장양념장 (부추 없을 때 ⭐ 강추 — 실전 검증!)**
- 간장 3 + 식초 1 + 설탕 0.5~1
- **양파 3~4큰술**(다지거나 **채썰기도 굿**) + 다진 마늘 0.5 + 고춧가루 1 + 참기름·깨
- (선택) 청양고추 + 백숙 국물 1큰술
- → 양파가 아삭함+단맛, 부추 못지않음. **찬물에 5분 담갔다 빼면** 매운맛↓ 순함
- 💬 *실제로 해보니 양파채 양념장 너무 맛있었음! 부추 없을 때 강추*

**③ 소금 참기름장 (제일 간단)**
- 소금 + 후추 + 참기름 + 깨 (+ 레몬즙/식초 살짝)
- → 파·부추 없어도 완성, 고소하게 찍먹

**④ 겨자 간장 (톡 쏘게)**
- 간장 2 + 연겨자 0.5 + 식초 1 + 설탕 0.5 → 느끼함 잡고 개운

> 파·부추 대신 **쪽파·대파·양파·미나리·깻잎** 아무거나 OK. 마늘·참기름·깨만 있으면 기본 완성.

## ⚠️ 찹쌀 바닥 눌어붙음 방지
- **바닥에 물이 꼭 깔리게** (마른 찹쌀이 바닥에 직접 닿으면 눌어붙음)
- 💡 **더 확실한 법:** 불린 찹쌀을 **면포/다시백에 넣어** 바닥에 두기 → 눌어붙음·추 막힘 없이 **찰밥 덩어리**로 나옴 (백숙집 방식, 서빙 깔끔)

## 🍚 닭죽으로 마무리 (남은 밥·국물)
- 남은 국물 + 밥(찰밥·현미·잡곡 다 OK) → 약불로 끓여 죽처럼
- **★ 마무리에 참기름 + 소금 + 깨 넣고 비비면 고소하고 맛있음** ⭐ (김가루 있으면 더 굿)
- 간은 소금으로, 심심하면 잡곡 묵은내도 더 느껴지니 **간 확실히**

> ⚠️ **누룽지는 "찹쌀/찰현미"라야 됨!** 일반 현미·보리·잡곡은 찰기가 없어 **누룽지 안 생기고 죽만 됨**(실패 아님, 곡물 특성). 누룽지 원하면 찰현미 쓰거나, 밥을 **팬에 얇게 펴 약불로 눌러** 수동 누룽지.

## TIP
- 데치기 + 향신채(대파·마늘·생강)면 닭 잡내 충분히 잡힘
- 국물 진하게: 황기·대추 넣고 끓이면 삼계탕 느낌
- 소금은 **먹기 직전 각자 찍어** 먹어도 좋음 (심심하게 끓여서)
