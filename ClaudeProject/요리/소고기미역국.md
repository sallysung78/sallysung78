# 소고기 미역국 (식당보다 맛있는 진한 버전)

> 원본(인스타 mamajo_cook)의 핵심 비법 + 맛 더 끌어올린 버전.
> **비법 = 미역 잠길 만큼만 물 붓고 센불 20분 먼저 끓이기**(농축) → 그다음 물 추가.
> 4~5인분.

---

## 재료 (4~5인분)
| 재료 | 분량 |
|------|------|
| 국거리 소고기 (양지·사태) | 300g |
| 불린 미역 | 30g |
| 양파 | 1개 |
| 들기름 | 3T |
| 물 | 3L (+ 처음 미역 잠길 만큼) |
| 분말육수 | 1포 |
| 참치액 | 2T |
| 국간장 | 2T |
| 다진 마늘 | 1~2T |
| 소금 | 마지막 간 |
| (선택) 사골육수 | 조금 → 더 진하게 |

### ✨ 맛 UP 추가 (원본 대비)
- **고기 밑간:** 국간장 0.5T + 참기름 + 후추 (볶기 전) → 감칠맛↑
- 후추 (마무리), (선택) 무 한 토막(시원), 마지막 참기름 한 바퀴

---

## 만드는 법
1. **미역 씻기 ★** — 불린 미역을 **손으로 바락바락 여러 번 씻어** 물기 빼기 (미끈함 빠져 부드럽고 국물 맑아짐)
2. **고기 준비** — 키친타월로 핏물 제거 + (밑간: 국간장·참기름·후추)
3. **고기 볶기** — 예열한 냄비에 **들기름 3T** 두르고 고기 **겉면만 살짝** 익히기
4. **미역 볶기** — 미역 넣고 **함께 2~3분 볶기** (다진 마늘 절반 이때 넣으면 향↑)
5. **★ 농축 끓이기 (핵심)** — **미역 잠길 정도로만 물 붓고 뚜껑 덮어 센불 20분** → 오래 안 끓여도 푹 끓인 깊은 맛
6. **물 붓기** — **물 3L + 분말육수 1포** (사골육수 조금 넣으면 더 진함 / 없으면 **쌀뜨물**도 굿)
7. **간** — 참치액 2T + 국간장 2T + 다진 마늘(나머지) → 끓이기. 모자란 간은 **마지막에 소금**
8. **양파 통으로 1개 넣고** 흐물해질 때까지 푹 끓이면 완성 (양파 단맛이 국물 깊게)
9. 후추·참기름 살짝 마무리

---

## 🔑 맛의 핵심 (왜 맛있나)
- **미역 바락바락 씻기** → 미끈함 제거, 부드럽고 국물 안 탁함
- **고기·미역 들기름에 볶기** → 고소함·감칠맛 (미역국 맛의 8할)
- **미역 잠길 만큼만 물 붓고 센불 20분** ⭐ → 국물이 **농축**돼 깊은 맛 (그 뒤 물 추가)
- **참치액 + 국간장 + 분말육수** 3중 감칠맛
- **양파 통째** 푹 끓여 단맛

## 💬 실전 Q&A (자주 묻는 것)
**🧂 볶을 때 간해도 되나?** — **살짝 O (밑간).** 미역·고기 볶을 때 **국간장 1작은술(or 소금 약간)** 넣으면 밑간 배어 감칠맛↑. 단 **진짜 간은 마지막에** (국물 졸면 짜짐). 국간장이 소금보다 감칠맛 좋음.

**🧅 통양파 넣으면?** — **좋음!** 통째(or 반 갈라) **처음~중간에** 넣고 흐물해질 때까지 푹 끓이면 **국물 달큰·깊게**. 조미료 없이도 맛있음. 먹기 전 건져내거나 두거나 취향. (중 1개 적당)

**🥩 편육이 질기면?** — 국물에 **얇게 썰어** 넣으면 국물에서 더 부드러워짐. 그래도 질기면 압력밥솥에 **국물 잠기게 넣고 찜 15~20분+자연감압**(마른 채 X → 퍽퍽).

## 🍲 남은 고기·국물로 초간단 버전
어제 삶은 사태 편육 + 국물 있으면 → 육수 낼 필요 없이 **20분**:
1. 미역 불려 씻어 → **들기름에 미역+마늘 볶기**(중불~중강불 2~3분)
2. **남은 국물 + 편육** 넣고(기름 걷고) 약중불 15~20분
3. 국간장·소금 마지막 간
> 어제 국물이 이미 소고기 육수라 오히려 진함. → 상세: `사태미역국-남은고기활용.md`

## ⚠️ 보관 (여름·환절기 주의)
- **끓인 국을 실온에 밤새 두지 말 것!** (17~20도도 세균 번식 → 상함)
- **얼음물에 냄비 받쳐 빨리 식혀 → 냉장** (2시간 내). 다음날 **팔팔 데워** 먹기
- **하루 뒤가 더 맛있음** (재우면 깊어짐) → 미리 끓여 냉장 추천. 냉장하면 기름 굳어 걷기 쉬움(담백)

## TIP
- 국간장으로 **색·감칠맛**, 소금은 마지막 미세 조정 (일찍 소금 X → 짜짐)
- 진하게: 사골육수 / 시원하게: 무 한 토막
- 양지=담백, 사태=젤라틴 부드러움 (섞어도 굿)
- 미역은 볶고 끓이는 걸 **너무 오래 X** (알긴산 나와 국물 탁·끈끈). 바락바락 씻기 + 적당히 끓이면 맑음
