# 검은콩 옥수수 감자 다이어트 스프

> 냉장고 속 검은콩·옥수수·감자로 뚝딱. 기름 없이 콩으로 걸쭉·든든.
> 포만감 좋아 아침 대용/저녁 가볍게 딱. 2~3인분.

---

## 재료 (2~3인분)
| 재료 | 분량 |
|------|------|
| 검은콩 (불린 것) | 1/2컵 |
| 옥수수알 | 1/2~1컵 |
| 감자 | 1개 (중) |
| 양파 | 1/2개 |
| 물 또는 채수 | 3~4컵 |
| 소금·후추 | 약간 |
| (선택) 우유/두유 | 1/2컵 (크리미하게) |

---

## 만드는 법
1. **검은콩 불리기** — 최소 3~4시간(가능하면 하룻밤). 압력솥이면 덜 불려도 OK.
2. **삶기**
   - 냄비: 검은콩 먼저 20~30분 → 감자·양파·옥수수 넣고 15~20분 (다 무를 때까지)
   - **압력솥:** 다 넣고 찜 15~20분 + **자연감압** (콩·감자 푹 익음, 훨씬 빠름)
3. **곱게 갈기** — 한 김 식혀 믹서/핸드블렌더로. (옥수수 조금 남겨 톡톡 씹는 맛 살려도 좋음)
4. **다시 데우기** — 소금·후추 간, 되직하면 물 추가 / (선택) 우유·두유 조금 넣어 부드럽게
5. 옥수수알·검은콩 몇 개 올려 장식

---

## 🥗 다이어트 포인트
- **기름·버터·크림 없이** 물·채수로 (감자·콩이 자연 걸쭉하게 해줌)
- **감자·옥수수는 탄수화물** → 다이어트면 **감자 1개·옥수수 1/2컵 소량**, 대신 **검은콩(단백질) 넉넉히**
- **양파**가 단맛 내줘 설탕 불필요
- 우유 대신 **두유**면 더 가벼움

## 🧈 크림 버전 (우유·버터 넣기) — 더 맛있게!
> 담백한 다이어트 스프 → **고소한 크림 스프**로 변신. 맛↑ (칼로리도↑, 든든한 브런치용).

**추가 재료:** 버터 1큰술 · 우유(또는 두유·저지방우유) 1/2~1컵

**넣는 법 (순서·타이밍 중요):**
1. **버터:** 맨 처음 **양파를 버터에 볶아** 향·단맛 내기 → 그다음 콩·감자·물 넣고 삶기
2. **우유:** **맨 마지막**, 곱게 간 뒤 데울 때 넣기
   - ⚠️ 우유 넣은 뒤엔 **약불로 살살** (센불에 팔팔 끓이면 **분리·눌어붙음**)
3. 소금·후추 간, 되직하면 우유·물 조금 더

**가볍게 + 맛 둘 다 원하면:** 버터 1작은술만 + **두유/저지방우유** → 크리미한데 덜 무거움

## 💪 포만감·영양
- 검은콩 = 식물성 단백질·식이섬유 → 오래 든든
- 갈아 먹으면 소화 편하고 한 그릇으로 배부름

## ⚠️ 팁
- **검은콩 충분히 불리고 푹 익히기** (덜 익으면 비린맛·소화 부담)
- 압력솥이면 콩·감자 순삭 → 제일 편함 (**자연감압!**)
- 고소함 원하면 **참깨·들깨가루** 살짝
