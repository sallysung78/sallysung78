# 참고자료 (Reference Materials)

이 폴더는 작업에 참고할 자료를 모아두는 공간입니다.

## 용도
- 삼성생명 가족보험 약관 등 보험 관련 문서
- 특약(특별약관) 분석용 원본 자료
- 기타 참고용 PDF / 문서

## 파일 업로드 방법 (GitHub 웹)
1. 이 폴더(`참고자료/`)로 이동
2. 우측 상단 **Add file → Upload files** 클릭
3. 약관 PDF 등을 드래그&드롭
4. **Commit changes** (브랜치: `claude/samsung-life-insurance-riders-3geytk`)

업로드 후 알려주시면, 해당 문서에서 특약 목록을 추출·분류·정리해 드립니다.
