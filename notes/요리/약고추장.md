# 약고추장 (다진 소고기 고추장 볶음)

> 다진 소고기를 고추장에 졸여 만드는 상비 양념.
> 비빔밥·쌈·오이고추 찍어먹기 등 두루두루. **자투리 살코기 활용**에 최고.
> 약 150g 기준 / 15분.

---

## 재료

| 재료 | 분량 |
|------|------|
| 다진 소고기 (자투리살 OK) | 150g |
| 고추장 | 4큰술 |
| 다진 양파 | 2큰술 (선택, 단맛·감칠맛) |
| 다진 마늘 | 1작은술 |
| 참기름 | 1큰술 |
| 꿀 또는 올리고당/물엿 | 1.5큰술 |
| 설탕 | 1작은술 |
| 물 | 3~4큰술 |
| 통깨·후추 | 약간 |

> **부채살 자투리 활용 시**: 흰 은막·굵은 힘줄은 제거하고, 너무 곱지 않게 약간 씹히는 굵기로 다진다. (지방·은막 많은 부위는 약고추장엔 부적합 → 육수·스튜용으로)

---

## 만드는 법

### 1. 고기 볶기
팬에 참기름 두르고 **다진 마늘 + 고기**를 핏기 가실 때까지 볶는다.

### 2. 양파 볶기
다진 양파를 넣고 투명해질 때까지 더 볶는다.

### 3. 졸이기 ★핵심
**고추장·꿀·설탕·물**을 넣고 **약불**에서 계속 저으며 5~10분 졸인다.
> 고추장은 잘 눌어붙으니 **약불 + 계속 젓기** 필수.

### 4. 마무리
되직하게 윤기 나면 **참기름 한 바퀴 + 통깨**를 넣고 끝.
완전히 식혀 밀폐 → **냉장 1~2주 / 냉동 보관도 OK**.

---

## TIP

- **농도**: 식으면 더 꾸덕해진다 → **약간 묽다 싶을 때 불 끄기**. 되면 물 조금, 묽으면 더 졸이기.
- **고소함 업**: 마무리에 **피넛버터 1/2작은술**(견과 대용) — 살짝만.
- **단맛 대체**: 꿀·설탕 대신 **양념치킨소스 1큰술**로도 가능.
- **굵기**: 너무 곱게 갈지 말 것. 약간 씹히는 게 더 맛있다.
