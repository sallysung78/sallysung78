# 약고추장 (다진 소고기 고추장 볶음)

> 다진 소고기를 고추장에 졸여 만드는 상비 양념.
> 비빔밥·쌈·오이고추 찍어먹기 등 두루두루. **자투리 살코기 활용**에 최고.

---

## 재료

### 소량 (약 150g 기준 / 15분)
| 재료 | 분량 |
|------|------|
| 다진 소고기 (자투리살 OK) | 150g |
| 고추장 | 4큰술 |
| 다진 양파 | 2큰술 |
| 다진 마늘 | 1작은술 |
| 참기름 | 1큰술 |
| 매실액 | **1큰술** (신맛 나니 조금만!) |
| 꿀 또는 올리고당/물엿 | 1.5큰술 |
| 설탕 | 1작은술 |
| 물 | 3~4큰술 |
| 후추 | 약간 (고기 볶을 때) |
| 통깨 | 약간 |

### 대용량 (고추장 500g 기준)
| 재료 | 분량 |
|------|------|
| 고추장 | 500g (약 2컵) |
| 다진 소고기 | 350~400g (넉넉히! 250g은 적게 느껴짐) |
| 다진 양파 | 1/2개 (약 5큰술) |
| 다진 마늘 | 1.5큰술 |
| 참기름 | 4~5큰술 |
| 매실액 | **2~3큰술** (신맛 나니 적게! 4큰술은 너무 셨음) |
| 올리고당(또는 물엿/꿀) | 5큰술 |
| 설탕 | 1큰술 (맛보고) |
| 물 | 약 1컵(200ml), 농도 보며 |
| 맛술(청주) | 2큰술 (선택, 누린내) |
| 후추 | 약간 (고기 볶을 때) / 통깨 2큰술 |

> **부채살 자투리 활용 시**: 흰 은막·굵은 힘줄 제거, 너무 곱지 않게 약간 씹히는 굵기로 다진다. (지방·은막 많은 부위는 약고추장엔 부적합 → 육수·스튜용)
> **고기 양**: 소고기는 넉넉히. 적으면 고추장만 도드라진다. (500g 고추장에 250g은 적었음 → 350g+ 권장)

---

## 만드는 법

### 1. 양파·마늘 볶기
팬에 **참기름** 두르고 **다진 양파** 먼저 볶다가(투명해질 때까지), **마늘**은 거의 끝날 때 넣어 향 내기.
> 마늘은 빨리 타니 나중에. 참기름이라 **약불~중불**.

### 2. 고기 볶기 — ★후추는 여기서!
다진 소고기를 넣고 핏기 가시고 갈색날 때까지 볶는다.
**이때 후추 넉넉히** (+맛술 있으면) → **누린내 잡기**.
> 양파·고기에서 물이 나오면 **흥건한 것만 졸여 날린 뒤** 다음 단계로. (완전히 마를 필요는 없음)

### 3. 졸이기 ★핵심
**고추장·매실액·올리고당(·설탕)**을 넣고 **약불**에서 계속 저으며 5~10분(대용량은 15~20분) 졸인다.
- 너무 빡빡하면 **물 조금** 넣어 풀기 (생고추장 맛 날아가게 끓여야 함)
- 생고추장 냄새 가시고 **윤기** 나면 완성 신호
> 고추장은 잘 눌어붙고 튄다 → **약불 + 계속 젓기 + 바닥 긁기** 필수.

### 4. 마무리
되직하게 윤기 나면 **참기름 한 바퀴 + 통깨**. 맛보고 간 조절.
완전히 식혀 밀폐 → **냉장 2~3주 / 냉동 소분 보관**.

---

## TIP

- **매실액 신맛 주의** ⚠️: 매실액은 새콤하니 **조금만**. 많이 넣어 시면 → **올리고당/꿀을 1큰술씩** 넣어 단맛으로 잡기 (+고기·고추장 추가하면 희석됨, 약불에 더 졸이면 둥글어짐). 식으면 신맛은 줄고 단맛은 더 느껴진다.
- **후추는 2번(고기 볶을 때)** 넣어야 누린내가 잡힌다. 졸인 뒤엔 효과 약함.
- **소금 넣지 말 것**: 고추장이 이미 짜다. 마지막에 싱거우면 그때만 아주 조금.
- **농도**: 식으면 더 꾸덕해진다 → **약간 묽다 싶을 때 불 끄기**.
- **고소함 업**: 마무리에 **피넛버터 1/2작은술**(견과 대용) — 살짝만.
- **단맛 대체**: 꿀·설탕 대신 **양념치킨소스 1큰술**로도 가능.
- **구수함**: 새콤하거나 밍밍하면 **된장 1/2작은술**로 잡아도 좋다.
- **굵기**: 너무 곱게 갈지 말 것. 약간 씹히는 게 더 맛있다.
- **고기 따로 추가 가능**: 만든 뒤 양 적으면, 소고기만 따로 볶아(물기 날리고 후추) 섞고 약불 2~3분. 섞으면 싱거워지니 간 다시 보기.
