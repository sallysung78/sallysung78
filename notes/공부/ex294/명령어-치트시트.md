# 📇 명령어 치트시트 (시험장 빠른 참조)

## 문서 찾기 (인터넷 없음 → 이게 생명줄)
```bash
ansible-doc -l                 # 모든 모듈 목록
ansible-doc dnf                # 모듈 옵션/예제
ansible-doc -s dnf             # 짧은 사용법(스니펫)
ansible-doc -l | grep -i firewall
ansible-config dump            # 현재 설정 확인
ansible --version              # 설정파일/모듈 경로 확인
```

## 임시 명령 (ad-hoc)
```bash
ansible all -m ping
ansible all -m setup                         # 팩트 보기
ansible all -m setup -a 'filter=ansible_eth*'
ansible web -m dnf -a 'name=httpd state=present' -b
ansible all -m command -a 'uptime'
ansible all -m copy -a 'src=/etc/hosts dest=/tmp/hosts' -b
ansible all -a 'id' -b                        # -m command 생략 가능
```
> `-b`(--become) 권한상승, `-m` 모듈, `-a` 인자.

## 플레이북 실행/검증
```bash
ansible-playbook site.yml --syntax-check
ansible-playbook site.yml -C                  # 체크모드(dry-run)
ansible-playbook site.yml --list-tasks
ansible-playbook site.yml --list-hosts
ansible-playbook site.yml --tags web
ansible-playbook site.yml --skip-tags db
ansible-playbook site.yml -e "pkg=nginx"
ansible-playbook site.yml --limit servera
ansible-playbook site.yml -v                  # -vvv 까지
ansible-playbook site.yml --start-at-task="이름"
ansible-playbook site.yml --step
```

## 인벤토리
```bash
ansible-inventory --list
ansible-inventory --graph
ansible-inventory --host servera
```

## Galaxy (롤/컬렉션)
```bash
ansible-galaxy role init roles/myrole
ansible-galaxy role install -r requirements.yml -p roles/
ansible-galaxy collection install -r requirements.yml -p collections/
ansible-galaxy collection list
ansible-galaxy role list
```

## Vault
```bash
ansible-vault create   secret.yml
ansible-vault encrypt  vars/secret.yml
ansible-vault decrypt  vars/secret.yml
ansible-vault view     secret.yml
ansible-vault edit     secret.yml
ansible-vault rekey    secret.yml
ansible-vault encrypt_string 'pw' --name 'db_pass'
ansible-playbook site.yml --vault-password-file vault-pass.txt
```

## 🆘 막혔을 때 순서
1. `ansible-doc <모듈>` 로 옵션 확인 (외우지 말고 찾기)
2. `--syntax-check` 로 YAML 오류 잡기
3. `-C` 로 동작 미리보기
4. `register` + `debug: var=...` 로 변수/팩트 확인
5. `-vvv` 로 상세 에러 보기
