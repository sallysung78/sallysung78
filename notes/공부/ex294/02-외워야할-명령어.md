## 📦 설치 / 초기 세팅
```bash
sudo dnf install -y ansible-*            # ansible 설치
sudo yum -y install rhel-system-roles    # RHEL 시스템 역할 설치 (timesync/selinux용)
ansible all -m ping                       # 연결 확인
```
> rhel-system-roles 가 안 깔리면 `rhel-*` 로 설치 시도.

## 🌐 Ansible Galaxy — ⭐ 두 가지 구분해서 외우기
```bash
# (1) 롤(role) 설치 : install -r
ansible-galaxy install -r roles/requirements.yml
ansible-galaxy install -r requirements.yml -p roles/    # 경로 지정

# (2) 콜렉션(collection) 설치 : collection install ~ -p ~
ansible-galaxy collection install <파일> -p <설치위치>
ansible-galaxy collection install -r requirements.yml -p /home/user/ansible/collections

# 커스텀 롤 뼈대 생성
ansible-galaxy init roles/apache
sudo ansible-galaxy init roles/apache     # 권한 필요 시
```
> 콜렉션은 보통 `wget` 으로 각 .tar.gz 파일을 먼저 받은 뒤 install.
> ⚠️ `install -r` (롤) vs `collection install -p` (콜렉션) — 헷갈리지 말 것.

## 🔐 Ansible Vault — 명령을 몸에 익히기
```bash
# 비밀번호 파일 만들기
echo 'thisissecert' > secret.txt
chmod 0600 secret.txt

# 암호화 / 보기 / 해독 / 키 재설정
ansible-vault encrypt locker.yml
ansible-vault encrypt --vault-password-file secret.txt locker.yml   # 외우기
ansible-vault view locker.yml
ansible-vault rekey --ask-vault-pass salaries.yml       # 키 다시 입력 (제일 쉬운 문제)
```
> ansible.cfg 에 `vault_password_file = /home/user/ansible/secret.txt` 지정하면 자동 적용.

## 📂 역할 README 위치 (변수명은 여기서 찾는다)
```bash
# 시스템 역할 README 경로 (외우기)
ls /usr/share/ansible/roles/
less /usr/share/ansible/roles/rhel-system-roles.timesync/README.md
cat /usr/share/ansible/redhat.rhel_system_roles.timesync/README.md

# 역할 디렉토리 빠르게 찾기 (TIP)
find /usr/share/ansible -type d -name "*timesync*"
find /usr/share/ansible -type d -name "*selinux*"
grep -R "timesync_ntp_servers" /usr/share/ansible/roles/
```

## ▶️ 실행 / 검증 (플레이북 만들면 꼭 실행해보기)
```bash
ansible-playbook <file>.yml                       # 실행
ansible-playbook <file>.yml --syntax-check        # 문법 검사
ansible-navigator run -m stdout <file>.yml        # navigator로 실행

# 결과 검증
ansible all -m command -a "<확인명령>"
ansible all -m setup | less                       # facts 전체 보기
ansible localhost -m setup | less                 # 변수명 확인용
```

## ✅ 문제별 검증 명령 (외워두면 빠름)
| 문제 | 검증 명령 |
|------|------|
| 패키지/repo | `ansible all -m command -a "yum repolist"` |
| timesync | `chronyc sources` |
| selinux | `sestatus` |
| 사용자 | `id <user>` · `chage -l <user>` · `getent group devops` |
| cron | `crontab -l -u natasha` · `grep CRON /var/log/cron` |
| LVM | `lvdisplay` · `lvs` · `lsblk` · `df -h` · `blkid` |
| 웹/템플릿 | `curl http://<host>/...` |
| 파일내용 | `cat /etc/issue` · `cat /root/hwreport.txt` |
