# 🔴 시스템 관리 모듈 치트시트 (약점 35% — 최우선 반복)

> 시험의 핵심. "이 작업 → 이 모듈" 이 자동으로 나와야 함.
> 옵션 까먹으면 `ansible-doc <모듈>` (FQCN 또는 짧은 이름).

## 📦 패키지 / 저장소
```yaml
- ansible.builtin.dnf:
    name: httpd          # 리스트도 가능: [httpd, mod_ssl]
    state: present       # present / latest / absent
- ansible.builtin.dnf:
    name: "@Development Tools"   # 그룹 설치
    state: present
- ansible.builtin.yum_repository:
    name: myrepo
    description: My Repo
    baseurl: http://repo.example.com/
    gpgcheck: true
    gpgkey: http://repo.example.com/RPM-GPG-KEY
    enabled: true
```

## 🔧 서비스
```yaml
- ansible.builtin.service:        # 또는 ansible.builtin.systemd
    name: httpd
    state: started               # started / stopped / restarted / reloaded
    enabled: true                # 부팅 시 자동 시작 (재부팅 채점 대비!)
```

## 🔥 방화벽 (firewalld)
```yaml
- ansible.posix.firewalld:
    service: http                # 또는 port: 8080/tcp
    state: enabled               # enabled / disabled
    permanent: true              # 영속 (재부팅 후 유지)
    immediate: true              # 즉시 적용
```

## 👤 사용자 / 그룹
```yaml
- ansible.builtin.group:
    name: developers
    state: present
- ansible.builtin.user:
    name: alice
    groups: developers           # 보조그룹
    append: true                 # 기존 그룹 유지
    password: "{{ 'pass' | password_hash('sha512') }}"
    shell: /bin/bash
    state: present
- ansible.posix.authorized_key:
    user: alice
    key: "{{ lookup('file', 'files/id_rsa.pub') }}"
```

## 📁 파일 / 디렉터리 / 내용
```yaml
- ansible.builtin.file:
    path: /app
    state: directory             # directory / touch / absent / link
    owner: root
    mode: '0755'
- ansible.builtin.copy:
    src: files/app.conf
    dest: /etc/app.conf
    owner: root
    mode: '0644'
- ansible.builtin.copy:
    content: "Hello\n"           # 인라인 내용
    dest: /etc/motd
- ansible.builtin.lineinfile:
    path: /etc/selinux/config
    regexp: '^SELINUX='
    line: 'SELINUX=enforcing'
- ansible.builtin.blockinfile:
    path: /etc/hosts
    block: |
      192.168.1.10 web1
      192.168.1.11 web2
```

## 💾 스토리지 (파티션 / LVM / 파일시스템 / 마운트)
```yaml
- community.general.parted:
    device: /dev/vdb
    number: 1
    state: present
    part_end: 1GiB
- community.general.lvg:
    vg: data_vg
    pvs: /dev/vdb1
- community.general.lvol:
    vg: data_vg
    lv: data_lv
    size: 500m                   # 확장: size +100m, resizefs: true
- community.general.filesystem:
    fstype: xfs
    dev: /dev/data_vg/data_lv
- ansible.posix.mount:
    path: /data
    src: /dev/data_vg/data_lv
    fstype: xfs
    state: mounted               # mounted = fstab 기록 + 마운트 (재부팅 유지!)
```
> ⚠️ 스왑/마운트는 **state: mounted** 로 fstab에 남겨야 재부팅 후에도 유지.

## ⏰ 스케줄 작업 (cron)
```yaml
- ansible.builtin.cron:
    name: "backup job"
    minute: "0"
    hour: "2"
    job: "/usr/local/bin/backup.sh"
    user: root
```

## 🗜️ 아카이브
```yaml
- community.general.archive:
    path: /var/log
    dest: /tmp/logs.tar.gz
    format: gz
- ansible.builtin.unarchive:
    src: /tmp/logs.tar.gz
    dest: /opt
    remote_src: true             # 원격에 이미 있는 파일이면 true
```

## 🔐 SELinux / 보안
```yaml
- ansible.posix.selinux:
    policy: targeted
    state: enforcing
- ansible.posix.seboolean:
    name: httpd_can_network_connect
    state: true
    persistent: true
```

## 🖥️ command vs shell vs raw
| 모듈 | 용도 |
|------|------|
| `command` | 기본. 셸 기능(파이프/리다이렉트) 없음. 멱등성 직접 관리 |
| `shell` | `|`, `>`, `$VAR` 등 셸 기능 필요할 때 |
| `raw` | 파이썬 없는 노드 부트스트랩용 |
```yaml
- ansible.builtin.command: /usr/bin/make_db
  args:
    creates: /var/db/initialized   # 이 파일 있으면 skip (멱등성)
  changed_when: false
```
