# 🔰 핵심 개념 정리 (변수 · 팩트 · 조건 · 반복 · 핸들러 · 태그 · 에러처리)

> 지난 시험 38%. 플레이북의 뼈대. 손에 익혀야 하는 패턴 모음.

## 변수 (Variables)
```yaml
# 플레이 안에서
vars:
  pkg: httpd
# 외부 파일
vars_files:
  - vars/main.yml
```
- 명령행: `ansible-playbook play.yml -e "pkg=httpd"`  (가장 높은 우선순위)
- 사용: `"{{ pkg }}"`, 딕셔너리 `"{{ user.name }}"`, 리스트 `"{{ ports[0] }}"`
- **변수 우선순위(낮→높)**: role defaults → inventory vars → host_vars/group_vars → play vars → `-e` extra vars

## 팩트 (Facts)
```yaml
- debug:
    var: ansible_facts['default_ipv4']['address']
```
- `ansible servera -m setup` — 전체 팩트 확인
- `ansible servera -m setup -a 'filter=ansible_mem*'` — 필터
- 자주 쓰는 팩트: `ansible_facts['hostname']`, `['distribution']`, `['distribution_version']`, `['default_ipv4']['address']`, `['devices']`
- 커스텀 팩트: 관리노드 `/etc/ansible/facts.d/*.fact` → `ansible_facts['ansible_local']`

## 조건 (when)
```yaml
- name: RedHat 계열만
  ansible.builtin.dnf:
    name: httpd
    state: present
  when: ansible_facts['os_family'] == "RedHat"

- name: 복합 조건
  debug: msg="ok"
  when:
    - ansible_facts['distribution'] == "RedHat"
    - ansible_facts['distribution_major_version'] | int >= 8
```

## 반복 (loop)
```yaml
- name: 여러 패키지
  ansible.builtin.dnf:
    name: "{{ item }}"
    state: present
  loop:
    - httpd
    - mariadb-server

- name: 딕셔너리 반복 (사용자 생성)
  ansible.builtin.user:
    name: "{{ item.name }}"
    groups: "{{ item.group }}"
  loop:
    - { name: alice, group: wheel }
    - { name: bob,   group: users }

- name: 리스트 변수 반복
  loop: "{{ user_list }}"
```

## 핸들러 (Handlers) — 변경 시에만 실행
```yaml
tasks:
  - name: 설정 복사
    ansible.builtin.template:
      src: httpd.conf.j2
      dest: /etc/httpd/conf/httpd.conf
    notify: restart httpd
handlers:
  - name: restart httpd
    ansible.builtin.service:
      name: httpd
      state: restarted
```
> 핸들러는 플레이 **끝에 한 번** 실행. 즉시 필요하면 `meta: flush_handlers`.

## 태그 (Tags)
```yaml
- name: 웹 설치
  ansible.builtin.dnf: { name: httpd, state: present }
  tags: web
```
- 실행: `ansible-playbook site.yml --tags web`
- 제외: `--skip-tags web`
- 특수태그: `always`, `never`

## 에러 처리 (Error handling)
```yaml
- block:
    - command: /bin/false
  rescue:
    - debug: msg="실패 복구"
  always:
    - debug: msg="항상 실행"

# 개별 태스크
- command: /might/fail
  ignore_errors: true
  register: result
- command: /next
  failed_when: "'ERROR' in result.stdout"
  changed_when: false
```

## register & debug (디버깅 필수)
```yaml
- command: hostname
  register: out
- debug:
    var: out.stdout
```
