# 3️⃣ 모듈과 역할 (외워야 할 Modules & Roles)

> "문제를 보면 먼저 **모듈명**을 잡는다." 키워드 → 모듈 매핑이 핵심.

---

## 🗺️ 문제 키워드 → 모듈/역할 매핑 (가장 중요)

| 유형 | 문제 키워드 | 열 모듈 / 역할 |
|------|------|------|
| Repo/Package | yum_repository, php, mariadb, RPM group | `yum_repository`, `yum` |
| Role | timesync, selinux, apache, balancer, phpinfo | role README, `ansible-galaxy` |
| File/Template | hosts.j2, /etc/issue, /webdev, hwreport | `template`, `copy`, `file`, `lineinfile` |
| Control | loop, when, block/rescue, default | (교재 Task Control + ansible-doc) |
| Vault/User/Cron | locker.yml, password_hash, natasha cron | `ansible-vault`, `user`, `group`, `cron` |

### 문제 → 검색어 빠른 변환
- "`/etc/issue` 내용 변경" → `copy` (content) 또는 `lineinfile`
- "`/webdev` 심볼릭 링크" → `file`
- "하드웨어 보고서 값 치환" → `get_url` + `lineinfile` + `loop`
- "파일 생성" → `copy` / "디렉토리·링크 생성" → `file`

## 🔧 외워야 할 핵심 모듈

### yum_repository (Repo 문제)
옵션: `name / description / file / baseurl / gpgcheck / gpgkey / enabled`
```yaml
ansible.builtin.yum_repository:
  name: EX294_BASE
  description: EX294 base software
  baseurl: http://yum.repo.red.hat.com/BaseOS
  gpgcheck: true
  gpgkey: http://yum.repo.red.hat.com/RHEL/RPM-GPG-KEY-redhat-release
  enabled: true
```
> ⚠️ `gpgcheck` 와 `gpgkey` 붙여쓰기 금지, gpgkey URL은 별도 줄.

### yum (Package 문제)
```yaml
yum:                      # 여러 패키지 = 리스트
  name:
    - php
    - mariadb
  state: present          # latest = 최신 업데이트
yum: { name: "@RPM Development Tools", state: latest }   # 그룹 = @
yum: { name: '*', state: latest }                         # 전체 업데이트
```

### template (Jinja2 배포)
```yaml
template:
  src: index.html.j2      # roles/x/templates/ 또는 templates/
  dest: /var/www/html/index.html
```

### copy (파일 생성 / inline content)
```yaml
copy:
  content: 'Development'   # 인라인 내용 (/etc/issue 문제)
  dest: /etc/issue
when: inventory_hostname in groups['dev']
```

### file (디렉토리 / 링크 / 권한 / SELinux)
```yaml
file:
  path: /webdev
  state: directory        # directory / link / touch / absent
  group: webdev
  mode: '2775'            # setgid(2) + rwxrwxr-x
  setype: httpd_sys_content_t   # 웹에서 읽게 하려면
file: { src: /webdev, dest: /var/www/html/webdev, state: link }
```

### get_url + lineinfile (hwreport 문제)
```yaml
- get_url: { url: "http://.../hwreport.empty", dest: /root/hwreport.txt }
- lineinfile:
    path: /root/hwreport.txt
    regexp: '^{{ item.hw_name }}='
    line: "{{ item.hw_name }}={{ item.hw_cont }}"
  loop: "{{ hw_all }}"
```

### user + group (사용자 계정)
```yaml
- group: { name: devops, state: present }
- user:
    name: "{{ item.name }}"
    password: "{{ pw_developer | password_hash('sha512') }}"   # SHA512
    groups: devops
    append: true
  loop: "{{ users }}"
```

### cron
```yaml
cron:
  name: add cron natasha
  minute: "*/2"
  user: natasha
  job: logger "EX294 in progress"
  # system crontab이면 cron_file: <파일명> 추가
```

### lvol + filesystem (LVM)
```yaml
lvol: { vg: research, lv: data, size: 1500m }
filesystem: { fstype: ext4, dev: /dev/research/data }
```

### service + firewalld (apache 롤)
```yaml
service: { name: httpd, state: started, enabled: true }
service: { name: firewalld, state: started, enabled: true }
firewalld: { service: http, state: enabled, permanent: true, immediate: true }
```

## 🎭 외워야 할 역할(Role)

### System Role (변수만 지정, tasks 없음)
```yaml
# timesync
roles:
  - rhel-system-roles.timesync     # 또는 redhat.rhel_system_roles.timesync
vars:
  timesync_ntp_servers:
    - hostname: 192.168.0.254
      iburst: true

# selinux
roles:
  - rhel-system-roles.selinux
vars:
  selinux_policy: targeted
  selinux_state: enforcing
```
> 역할 이름은 설치 방식에 따라 `rhel-system-roles.*` 또는 `redhat.rhel_system_roles.*` — README에서 확인.

### Custom Role (apache) — 구조 + tasks + template
```
roles/apache/
  tasks/main.yml          # yum(httpd) → service(httpd,firewalld) → firewalld → template
  templates/index.html.j2 # Hello Apache from {{ ansible_fqdn }} on {{ ansible_default_ipv4.address }}
```
호출 플레이북(run-role.yml): `roles: - apache`

### Galaxy Role (balancer, phpinfo) — requirements.yml
```yaml
# roles/requirements.yml
- name: balancer
  src: http://ansible.galaxy.com/materials/haproxy.tar
- name: phpinfo
  src: http://ansible.galaxy.com/materials/phpinfo.tar
```
설치: `ansible-galaxy install -r requirements.yml`
