# ⚙️ 제어노드 구성 · 인벤토리 (강점 영역 — 복습용)

> 지난 시험 100% 영역. 빠르게 세팅하고 넘어가는 게 목표.

## 1. 설치
```bash
# RHEL 9 / AAP
sudo dnf install -y ansible-core
ansible --version
# 컬렉션 설치 (예: 시험에서 제공되는 컬렉션 tar)
ansible-galaxy collection install ansible.posix community.general
```

## 2. ansible.cfg (작업 디렉터리에 둠)
```ini
[defaults]
inventory      = ./inventory
remote_user    = devops
roles_path     = ./roles
collections_path = ./collections
host_key_checking = False

[privilege_escalation]
become         = True
become_method  = sudo
become_user    = root
become_ask_pass = False
```
> 우선순위: `ANSIBLE_CONFIG` 환경변수 > `./ansible.cfg` > `~/.ansible.cfg` > `/etc/ansible/ansible.cfg`

## 3. 정적 인벤토리 (INI)
```ini
[webservers]
servera.lab.example.com
serverb.lab.example.com

[dbservers]
serverc.lab.example.com

[prod:children]
webservers
dbservers

[webservers:vars]
http_port=80
```

## 4. 정적 인벤토리 (YAML)
```yaml
all:
  children:
    webservers:
      hosts:
        servera.lab.example.com:
        serverb.lab.example.com:
    dbservers:
      hosts:
        serverc.lab.example.com:
```

## 5. SSH 키 배포 & 권한
```bash
ssh-keygen -N '' -f ~/.ssh/id_rsa
ssh-copy-id devops@servera.lab.example.com
# 또는 플레이북으로 (ansible.posix.authorized_key / user 모듈)
```

## 6. 연결 검증
```bash
ansible all -m ping
ansible all -m command -a 'id' --become
ansible-inventory --list          # 인벤토리 구조 확인
ansible-inventory --graph         # 트리 보기
```

## 자주 쓰는 인벤토리 패턴
- `ansible webservers -m ping` — 그룹 지정
- `ansible 'web*' -m ping` — 와일드카드
- `ansible all:!dbservers` — 제외
- `ansible webservers:dbservers` — 합집합
