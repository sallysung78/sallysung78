# 📝 플레이와 플레이북 작성 (약점 45%)

> YAML 문법 실수 + import/include 혼동이 감점 포인트.

## 기본 플레이북 골격
```yaml
---
- name: 웹 서버 구성
  hosts: webservers
  become: true
  vars:
    pkg: httpd
  tasks:
    - name: 패키지 설치
      ansible.builtin.dnf:
        name: "{{ pkg }}"
        state: present
    - name: 서비스 시작
      ansible.builtin.service:
        name: "{{ pkg }}"
        state: started
        enabled: true
  handlers:
    - name: restart web
      ansible.builtin.service:
        name: "{{ pkg }}"
        state: restarted
```

## YAML 주의 (감점 단골)
- 들여쓰기는 **공백**만 (탭 금지)
- `:` 뒤에 공백 1칸
- 값에 `{{ }}`로 시작하면 **따옴표로 감싸기**: `name: "{{ pkg }}"`
- 불리언: `true/false` (YAML 1.1의 yes/no도 되지만 통일 권장)
- `---` 로 문서 시작, 리스트는 `-`

## import vs include
| 구분 | import (정적) | include (동적) |
|------|------|------|
| 시점 | 플레이북 **파싱 시** 펼침 | **실행 시** 결정 |
| 태그 | 부모 태그가 자식에 전파 | 전파 안 됨 (개별 지정) |
| loop | 불가 | 가능 |
| 종류 | `import_tasks`, `import_role`, `import_playbook` | `include_tasks`, `include_role` |
```yaml
tasks:
  - import_tasks: setup.yml          # 항상 펼쳐짐
  - include_tasks: "{{ os }}.yml"    # 변수로 동적 선택
    when: ansible_facts['os_family'] == "RedHat"
```

## 여러 플레이 + import_playbook
```yaml
# site.yml
- import_playbook: web.yml
- import_playbook: db.yml
```

## block (그룹화 + 에러처리)
```yaml
tasks:
  - block:
      - dnf: { name: httpd, state: present }
      - service: { name: httpd, state: started }
    when: ansible_facts['os_family'] == "RedHat"
    become: true
    rescue:
      - debug: { msg: "설치 실패" }
```

## 검증 워크플로 (시험 필수 습관)
```bash
ansible-playbook site.yml --syntax-check   # 문법 검사
ansible-playbook site.yml -C               # 체크모드 (dry-run)
ansible-playbook site.yml --list-tasks     # 태스크 목록
ansible-playbook site.yml --list-hosts     # 대상 호스트
ansible-playbook site.yml -v               # 상세 (vvv까지 가능)
ansible-playbook site.yml --step           # 한 태스크씩 확인
ansible-playbook site.yml --start-at-task="패키지 설치"
```

## delegate / run_once / serial
```yaml
- name: 로드밸런서에서 제외 (제어노드/특정호스트 대행)
  command: /remove_from_lb
  delegate_to: lb.example.com

- name: 한 번만 실행
  command: /init_db
  run_once: true

- hosts: webservers
  serial: 2          # 2대씩 롤링 업데이트
```
