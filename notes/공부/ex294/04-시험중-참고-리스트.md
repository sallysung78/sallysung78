# 4️⃣ 시험 중 참고할 수 있는 것들 (Look-up Cheatsheet)

> 시험은 인터넷이 없지만 **로컬 문서는 사용 가능**.
> 외우지 말고 **찾아 쓰는 것**들 리스트업. → 암기 부담을 줄이는 핵심 스킬.

---

## 🔍 ① ansible-doc — 시험장의 검색 엔진
```bash
ansible-doc <module>                 # 모듈명이 생각나면: 전체 문서
ansible-doc -l | grep <keyword>      # 모듈명이 애매하면: 키워드로 검색
ansible-doc -s <module>              # 옵션만 빠르게 (스니펫)
ansible-doc <module>  → /EXAMPLES    # 문서 열고 /EXAMPLES 검색해 예제만
```
### 자주 쓰는 예
```bash
ansible-doc -l | grep repo
ansible-doc yum_repository
ansible-doc yum            # 열고 /EXAM 으로 검색해 설치 블록 긁기
ansible-doc -s user
ansible-doc cron
ansible-doc lineinfile
ansible-doc copy           # content 옵션 찾기
ansible-doc file           # state/mode/setype
ansible-doc template
ansible-doc firewalld
ansible-doc lvol
ansible-doc filesystem
```
> 💡 팁: 문제 풀 때 `ansible-doc yum` 열고 **`/EXAM`** 으로 검색하면 바로 쓸 수 있는 EXAMPLES 블록이 나옴. 그걸 긁어서 값만 수정.

## 📊 ② setup (ansible_facts) — 변수명/값 찾기
```bash
ansible all -m setup | less                          # 전체 facts
ansible localhost -m setup | less                    # 변수명 확인용 (외우기)
ansible localhost -m setup -a 'filter=ansible_fqdn'
ansible localhost -m setup -a 'filter=ansible_default_ipv4'
ansible all -m setup -a 'filter=ansible_lvm'         # LVM 정보
ansible localhost -m setup -a 'filter=ansible_mem*'
```
### 자주 쓰는 facts (값은 setup에서 확인)
```jinja
{{ ansible_facts['hostname'] }}          # 호스트네임
{{ ansible_facts['fqdn'] }}              # FQDN
{{ ansible_facts['default_ipv4']['address'] }}   # IP
{{ ansible_memtotal_mb | default('NONE', true) }}    # 총 메모리(MB)
{{ ansible_bios_version | default('NONE', true) }}   # BIOS 버전
{{ ansible_devices.vda.size | default('NONE', true) }}  # 디스크 크기
```
> 👉 fact 이름은 **외우는 게 아니라** setup 결과에서 filter/검색으로 확인한다.

## 📂 ③ Role / Collection 문서 — README와 navigator
> System Role(timesync/selinux/storage/network) 문제는 **"변수명"이 정답**.
> 변수명은 외우지 말고 README/문서에서 찾는다.

```bash
# 설치된 롤/콜렉션 목록
ansible-galaxy list
ansible-galaxy collection list

# 콜렉션 문서 인터랙티브 탐색
ansible-navigator collections -m interactive
#   → redhat.rhel_system_roles → storage/network → docs

# 롤 README 직접 보기
less /usr/share/ansible/roles/rhel-system-roles.timesync/README.md
grep -R "timesync_ntp_servers" /usr/share/ansible/roles/

# 롤 디렉토리 찾기 (TIP)
find /usr/share/ansible -type d -name "*timesync*"
find /usr/share/ansible -type d -name "*selinux*"
```
### 시험장 루틴 (System Role)
1. 역할 이름 확인 → 2. README에서 Example 찾기 → 3. vars 블록만 요구사항에 맞게 수정 → 4. 실행 후 검증

## ⚙️ ④ 설정/경로 확인
```bash
ansible-config dump                    # 현재 설정 전체
ansible-config dump | grep PATH        # roles_path / collections_path 확인
ansible --version                      # 설정파일·모듈 경로
ansible-inventory --list               # 인벤토리 구조
ansible-inventory --graph              # 트리 보기
```

## ⚠️ ⑤ 감점 방지 체크리스트 (오타/함정)
| 함정 | 체크할 것 |
|------|------|
| yum_repository | `gpgcheck`/`gpgkey` 붙여쓰기 금지, gpgkey URL 별도 줄 |
| timesync | 문제의 NTP IP와 예시 IP 다르면 **문제 원문 값** 사용 |
| template hosts | 한 호스트 = 한 줄 (IP FQDN shortname) |
| when 조건 | `inventory_hostname` vs `ansible_hostname` 구분, 오타 금지 |
| users.yml | `password_expire_max` 들여쓰기, user_list.yml 파일명 확인 |
| curl 확인 | `/hello.php/hello.php` 경로 중복 입력 금지 |
| vault | 비밀번호 철자 확인 (슬라이드와 시험 원문 다를 수 있음) |
| inventory | 정적 인벤토리 첫 줄 `---` 없음! |

> **최종 기준은 슬라이드 풀이가 아니라 "문제 원문 + ansible-doc/README".**
