# 🔴 롤(Roles)과 컬렉션(Collections) (약점 39%)

> 시험에 **거의 무조건 출제**. 롤 만들기/사용하기 + Galaxy 설치를 손에 익혀야 함.

## 롤 디렉터리 구조
```
roles/myrole/
├── defaults/main.yml      # 기본 변수 (우선순위 가장 낮음, 덮어쓰기용)
├── vars/main.yml          # 롤 변수 (우선순위 높음)
├── tasks/main.yml         # 핵심: 태스크
├── handlers/main.yml      # 핸들러
├── templates/             # Jinja2 (.j2) — template 모듈이 여기서 찾음
├── files/                 # copy 모듈이 여기서 찾음
├── meta/main.yml          # 의존성, 메타데이터
└── README.md
```

## 롤 생성
```bash
ansible-galaxy role init roles/myrole
# 또는 ansible-galaxy init --init-path roles/ myrole
```

## 롤 사용 (플레이북에서)
```yaml
- hosts: webservers
  roles:
    - role: myrole
      vars:
        http_port: 8080
```
또는 태스크 안에서 동적으로:
```yaml
  tasks:
    - import_role:   { name: myrole }   # 정적 (파싱 시 포함)
    - include_role:  { name: myrole }   # 동적 (실행 시 포함, loop 가능)
```

## 🌐 Galaxy에서 롤/컬렉션 설치
```bash
# 단일 설치
ansible-galaxy role install geerlingguy.nginx
ansible-galaxy collection install community.general

# 특정 경로에 설치 (시험 빈출!)
ansible-galaxy collection install community.general -p ./collections

# requirements.yml 로 일괄 설치
ansible-galaxy role install -r requirements.yml -p roles/
ansible-galaxy collection install -r requirements.yml -p collections/
```

## 📄 requirements.yml (롤 + 컬렉션 함께)
```yaml
---
roles:
  - name: geerlingguy.nginx
    version: "3.1.4"
  - src: http://example.com/roles/myrole.tar.gz
    name: myrole
  - src: https://github.com/user/repo.git
    scm: git
    version: main
    name: gitrole

collections:
  - name: community.general
    version: ">=5.0.0"
  - name: ansible.posix
```
> ⚠️ 시험에서 자주: "requirements.yml로 롤들을 `roles/`에 설치하라" →
> `ansible-galaxy role install -r requirements.yml -p roles/`

## 컬렉션 사용 (FQCN)
```yaml
- hosts: all
  collections:
    - community.general
  tasks:
    - parted: { device: /dev/vdb, number: 1, state: present }  # FQCN 생략 가능
    # 권장: 항상 FQCN 사용
    - community.general.parted: { device: /dev/vdb, number: 1, state: present }
```

## 시스템 롤 (RHEL System Roles)
```bash
sudo dnf install rhel-system-roles
# 보통 /usr/share/ansible/roles/ 에 redhat.rhel_system_roles.* 로 제공
```
```yaml
- hosts: all
  roles:
    - redhat.rhel_system_roles.timesync
  vars:
    timesync_ntp_servers:
      - hostname: time.example.com
        iburst: true
```
> 자주 나오는 시스템 롤: `timesync`, `selinux`, `firewall`, `storage`, `kernel_settings`.
> 변수는 **롤 문서(README, `/usr/share/doc`)** 에서 확인.

## 롤 vs 컬렉션 한 줄 정리
- **롤** = 재사용 가능한 태스크/핸들러/변수/템플릿 묶음
- **컬렉션** = 롤 + 모듈 + 플러그인을 패키징한 배포 단위 (FQCN: `네임스페이스.컬렉션.모듈`)
