> "손에 익히기"가 합격 열쇠. 푼 문제를 여기에 영역별로 쌓아가요.

## 정리 양식 (복붙해서 쓰기)
```markdown
## 문제 N. <한 줄 요약>
**요구사항**: ...
**풀이**:
\`\`\`yaml
# 플레이북 / 명령
\`\`\`
**검증**: ansible-playbook xxx.yml --syntax-check && -C
**외울 것 / 함정**: ...
```

## 영역별 파일 (채워나가기)
- `플레이북-기본-lab.md` — 패키지/서비스/방화벽 기본 플레이
- `모듈-시스템관리-lab.md` — 스토리지/사용자/cron 등 (약점 35%)
- `롤-컬렉션-lab.md` — 롤 생성·requirements 설치 (약점 39%)
- `vault-템플릿-lab.md` — Vault·Jinja2 (약점 33%)
