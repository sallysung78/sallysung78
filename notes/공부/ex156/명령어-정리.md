# 명령어 정리 (ex156)

> ex156 폴더 전체 md 파일에서 추출·중복 제거. **virtctl → oc → 그밖의** 순서.
> 표기: `<vm>` VM / `<dv>` DataVolume / `<svc>` Service / `<vol>` 볼륨 / `<ns>` 네임스페이스

---

## [1] virtctl

```bash
# 전원
virtctl start | stop | restart | pause | unpause   <vm>

# 접속
virtctl ssh <user>@<vm>            # 주입한 SSH키로 암호 없이
virtctl ssh -i ~/.ssh/id_rsa <user>@<vm>
virtctl console <vm>               # 시리얼 콘솔 (Ctrl+] 로 나옴, 암호 필요)
virtctl vnc <vm>                   # 그래픽(VNC) 콘솔

# 노출 (Service 생성)
virtctl expose vm <vm> --name=<svc> --type=ClusterIP    --port=80 --target-port=80
virtctl expose vm <vm> --name=<svc> --type=LoadBalancer --port=22 --target-port=22
virtctl expose vm <vm> --name=<svc> --type=NodePort     --port=22 --target-port=22

# 볼륨 핫플러그
virtctl addvolume    <vm> --volume-name=<dv> [--persist]   # --persist=재부팅 후에도 유지
virtctl removevolume <vm> --volume-name=<dv>

# 이미지 / 게스트 디스크
virtctl image-upload dv <name> --size=NGi --image-path=FILE [--storage-class=SC] [--insecure]
virtctl guestfs <volume> [-n <ns>]                # PVC 디스크 열기 (콘솔 불가, CLI만)

# Export
virtctl vmexport create   --vm=<vm> <export>      # 또는 --snapshot=<snap>
virtctl vmexport download <export> --vm=<vm> --volume=<vol> --output=disk.img.gz
virtctl vmexport download <export> --keep-vme --manifest --include-secret --output <file>.yml
virtctl vmexport delete   <export>

# VM 생성 / 복제
virtctl create vm    --name=<vm> --volume-pvc=src:<dv>          | oc apply -f -
virtctl create clone --source-name <src> --target-name <tgt>   | oc apply -f -   # 자동시작 X → 수동 start

# 기타
virtctl migrate <vm>               # 라이브 마이그레이션
virtctl version
virtctl <키워드> --help            # 예: virtctl vmexport --help / virtctl --help
```

## [2] oc

```bash
# 로그인 / 프로젝트
oc login -u <user> -p <pw> https://api.ocp4.example.com:6443
oc login --token=sha256~... --server=https://api.ocp4.example.com:6443
oc login --web
oc whoami --show-console
oc new-project <p> ; oc project <p>

# 상태 / 조회
oc get node && oc get csr && oc get co            # 클러스터 상태(노드/인증서/오퍼레이터)
oc get vm,vmi,dv,pvc                              # 한 번에
oc get vm | vmi | dv | pvc | sc | svc | route
oc get nad (net-attach-def) | endpoints | vmexport
oc get virtualmachinesnapshot | virtualmachineclone | volumesnapshots
oc get nncp,nnce                                  # NMState 정책/실행
oc get metallb,ipaddresspool,l2advertisement -n metallb-system
oc get network/cluster -o yaml                    # Pod/Service CIDR (관리자)
oc get pvc <name> -o jsonpath='{.spec.storageClassName}{"\n"}'
oc get svc <svc> -o jsonpath='{.status.loadBalancer.ingress[0].ip}'
oc get events --sort-by=.lastTimestamp -n <ns>

# 생성 / 적용
oc apply -f <file>.yaml                           # 없으면 생성·있으면 업데이트(재실행 안전)
oc create route edge --service <svc> --hostname <host>   # 암호화(edge|passthrough|reencrypt)
oc create service clusterip <name> --tcp=80:80
oc create secret generic <name> --from-file=key1=~/.ssh/id_rsa.pub

# 노출 (Route)
oc expose service/<svc> --name=<route> --port=8080 [--hostname=<h>] [--path=/x]

# 수정 / 삭제
oc edit vm <vm> | edit pvc <pvc> | edit service <svc>
oc set selector svc/<svc> <key>=<val>
oc label pod virt-launcher-<...> <key>=<val>
oc delete vm <vm> | delete dv <dv> -n <ns> | delete virtualmachinesnapshot <snap>

# 디버그 / 설명
oc describe vm <vm> | describe vmexport/<export>
oc explain dv.spec
oc <명령> --help
```

## [3] 그밖의 명령어

> 대부분 **VM 안(게스트)** 또는 **guestfs 컨테이너 안**에서 실행. (위치 구분 주의)

```bash
# ── 게스트(VM 안): virtctl ssh/console 접속 후 ──
touch ~/update_failed.txt              # 빈 파일(스냅샷 복원 시뮬)
lsblk                                  # 디스크/파티션 확인
df -h /dev/sda                         # FS 용량/사용률
sudo xfs_growfs /dev/sda               # XFS 확장 (ext4면 sudo resize2fs /dev/sda)
ip address                             # 인터페이스/IP (enp1s0=primary)
sudo systemctl enable --now <svc>      # 부팅 시 시작+즉시 실행
sudo systemctl status <svc>
sudo journalctl -u <svc> -p notice --since "1m ago"
hostnamectl ; last                     # 머신ID·호스트명 / 로그인 기록

# ── guestfs 컨테이너 안: virtctl guestfs 진입 후 (VM 중지) ──
virt-sysprep -a /dev/vda               # 봉인(고유정보 제거). 디스크는 항상 /dev/vda
virt-sysprep --list-operations
virt-sysprep -a /dev/vda --enable ca-certificates,user-account --remove-user-accounts cloud-user
virt-filesystems -a /dev/vda ; virt-edit ; virt-customize ; guestfish
exit                                   # 봉인 후 VM 시작 금지!

# ── 검증 / 접속 / 전송 ──
nc -vz <EXTERNAL-IP> 22                 # TCP 연결 확인(LB 검증)
curl http://<IP> [--connect-timeout 3] # HTTP 확인 / 격리 확인
getent hosts <svc>.<ns>.svc.cluster.local   # 포드 안 DNS 확인
ssh <user>@<IP> | ssh -i <key> <user>@<IP> | ssh server.srv -J <jump>
scp <user>@<host>:/path/file.yaml .     # Import 시 yaml 가져오기

# ── DB 백업 (보조 NIC 활용 예) ──
mysqldump -v -h <IP> -u <user> -p'<pw>' --all-databases > backup.sql

# ── kubectl + CLI 설치 ──
kubectl version --client ; kubectl help
curl -LO "https://mirror.openshift.com/.../openshift-client-linux-<ver>.tar.gz"
sha256sum -c --ignore-missing sha256sum.txt
tar -xvf <file>.tar.gz
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
```

## 📍 명령 실행 "위치" 구분 (제일 헷갈림)
| 명령 | 어디서 |
| --- | --- |
| `virtctl` / `oc` / `kubectl` | **워크스테이션** (클러스터 제어) |
| `touch`/`lsblk`/`xfs_growfs`/`systemctl`/`ip` | **VM 안** (ssh/console 접속 후) |
| `virt-sysprep`/`virt-edit`/`guestfish` | **guestfs 컨테이너 안** (VM 중지) |
| `getent` | **클러스터 내 포드 안** |

> ⭐ 진짜 외울 CLI(콘솔 불가): **① 봉인 `virtctl guestfs`+`virt-sysprep -a /dev/vda` ② export `virtctl vmexport download`.**
